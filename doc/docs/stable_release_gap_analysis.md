# Lv-00 vs 竞品对比分析

## 对比对象

| 系统 | 类型 | 定位 |
|------|------|------|
| GeoGebra | 动态几何 | 教育/可视化 |
| Lean 4 | 定理证明器 | 数学形式化 |
| SymPy | 符号计算 | 计算机代数 |
| Z3 | SMT Solver | 约束求解 |

## Lv-00 定位

Lv-00 是**编译器形式化验证框架**，不是动态几何软件、通用定理证明器、
符号计算库或 SMT solver。其核心价值在于：

- 自举编译器（编译器编译自身）
- 形式化正确性定理（simulation、preservation）
- 多层 IR 验证链

## 已知限制

- Lv-00 不是通用定理证明器，证明能力远弱于 Lean 4
- 几何构造能力有限，不替代 GeoGebra
- 无 SMT 求解能力，不可替代 Z3
- 生态与文档尚处早期阶段

## 差异化优势

- **唯一** 同时提供自举编译器和形式化验证的几何 DSL 框架
- 验证链透明可审计
- Lean 4 集成，定理可在证明助手中检查
