# GAP ANALYSIS — Lv-00 深度审计

## 对标: CompCert

CompCert 是 C 编译器形式化验证的黄金标准，提供从 Clight 到汇编的完整正确性链。
以下将 Lv-00 与 CompCert 进行体系级对比。

## v1.0 → v1.1.0 演进

### v1.0 状态（已归档）

v1.0 以"自举"为核心目标，实现了：

- lvLang 语法与求值器
- lvIR 中间表示
- Compiler: 源码 → IR 编译
- 基础定理: determinism、type_safety

**定位**: 自举完备的编译器原型。

### v1.1.0 正式发布（2026-07-24）

| 维度 | v1.0 (自举基线) | v1.1.0 (已验证基线) |
|------|----------------|---------------------|
| 语义规格 | 隐式（代码即规格） | 显式 operational semantics |
| 参考实现 | 编译器自身 | 独立参考解释器 |
| 定理库 | ~208（基础） | ~300（含 simulation、preservation、interop） |
| 验证层数 | 1（编译） | 3（Lang→IR→Cv00） |
| 对标 CompCert | 无 | 4/12 pass |
| 测试覆盖 | 无系统测试 | ~138 测试（137 通过） |
| 源文件 | 232 .c | 401 .c + 229 .h + 84 .lean |

v1.1.0 的修正体现在三个方面：

1. **语义规格**: 从"编译器产生正确输出"的直觉，转向可独立检查的操作语义
2. **参考实现**: 引入独立参考解释器，编译器正确性 = 编译器输出与参考解释器一致
3. **定理库**: 从零散的类型安全定理，扩展为覆盖多层的 simulation 链

Lv-00 目前对标 CompCert 约 4/12 编译 pass 的验证深度。剩余差距主要在优化 pass 验证和汇编层验证。
