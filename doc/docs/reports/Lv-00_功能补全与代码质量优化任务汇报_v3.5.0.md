### 3.2 web-gui 模块 (TypeScript/React)

#### 改进 1: useEngineStream 错误回调 (v3.5.0)
- **文件**: `web-gui/src/hooks/useEngineStream.ts`
- **问题**: TODO 标记 - 引擎连接错误时未向用户展示 Toast 通知
- **修复方案**: 添加 `onError` 回调选项，支持外部注入错误处理逻辑
- **代码变更**:
  ```typescript
  interface UseEngineStreamOptions extends StreamManagerConfig {
    /** 是否在组件挂载时自动连接引擎（默认 false） */
    autoConnect?: boolean;
    /** 引擎错误回调（用于向用户展示连接错误信息等） */
    onError?: (error: Error) => void;
  }
  ```
- **优先级**: 中优先级
- **状态**: ✅ 已完成

#### 改进 2: Layout 组件集成错误通知
- **文件**: `web-gui/src/components/layout/Layout.tsx`
- **问题**: useEngineStream 的错误未向用户展示
- **修复方案**: 集成 onError 回调，使用 Toast 展示错误信息
- **代码变更**:
  ```typescript
  useEngineStream({
    engineUrl: 'ws://localhost:3456',
    autoConnect: false,
    onError: (error: Error) => {
      const addToast = useAppStore.getState().addToast;
      addToast('error', `引擎连接错误: ${error.message}`);
      useAppStore.getState().appendLog(`引擎连接错误: ${error.message}`, 'error');
    },
  });
  ```
- **优先级**: 中优先级
- **状态**: ✅ 已完成

#### 新增 3: 函数块组合功能 (v3.5.0)
- **文件**: 
  - `web-gui/src/utils/funcBlockPresets.ts` (新增函数)
  - `web-gui/src/components/panels/BlockPanel.tsx` (集成UI)
- **问题**: 组合、乘积、部分应用功能仅有日志输出，无实际实现
- **新增功能**:

  1. **组合 (Compose)** - `composeBlocks()`
     - 将两个函数块串联
     - 第一个的输出作为第二个的输入
     - 支持点击选择交互

  2. **乘积 (Product)** - `productBlocks()`
     - 将两个函数块并行执行
     - 输入为两者输入的并集
     - 输出为两者输出的并集

  3. **部分应用 (Partial Apply)** - `partialApplyBlock()`
     - 固定函数块的某些输入参数
     - 生成接受更少输入的新函数块
     - 支持柯里化 (Currying)

  4. **兼容性验证** - `validateComposition()`
     - 检查两个函数块是否可以组合
     - 验证输出/输入类型兼容性

- **代码变更**:
  ```typescript
  // 新增导出函数
  export function composeBlocks(block1, block2, block1Outputs?): CompositionResult
  export function productBlocks(block1, block2): ProductResult
  export function partialApplyBlock(block, fixedInputIndices, fixedInputValues): PartialApplyResult
  export function validateComposition(block1, block2): boolean
  ```

- **UI 改进**:
  - 用户块列表支持点击选择
  - 组合/乘积操作状态实时显示
  - 取消操作按钮
  - Toast 通知反馈

- **优先级**: 中优先级
- **状态**: ✅ 已完成
