# Lv-00 编程魔法模块 - 开发者文档

## 概述

Lv-00 编程魔法模块是一个基于轰界世界观和 Lv-00 核心系统的魔法模拟器。它将 Lv-00 的几何元语言系统映射为魔法概念，实现了"用代码施展魔法"的独特体验。

## 系统架构

### 核心概念映射

| Lv-00 系统 | 魔法概念 | 说明 |
|-----------|----------|------|
| 符号坐标 | 符文 (Rune) | 魔法的基本构建块 |
| 约束图 | 魔法阵 (MagicArray) | 符文之间的关系和约束 |
| 函数块 | 咒语 (Spell) | 封装好的施法流程 |
| 类型系统 | 元素系统 | 轰界四元素体系 |
| 递归系统 | 领域 (Domain) | 高级魔法结构 |

## API 参考

### JavaScript 模块 (magic_module.js)

#### 创建实例

```javascript
var magic = lvMagic.createMagic();
```

#### 符文系统

```javascript
// 创建符文
var rune = magic.createRationalRune(1, 1, lvMagic.Element.FIRE);

// 设置强度
magic.setRunePower(rune, 5);

// 获取值
var value = magic.getRuneValue(rune);
```

#### 魔法阵系统

```javascript
// 创建魔法阵
var array = magic.createArray();

// 添加符文
magic.addRuneToArray(array, rune);

// 添加约束
magic.addConstraintToArray(array, lvMagic.ArrayConstraint.CONNECTION, 0, 1);

// 计算稳定性
var stability = magic.calculateArrayStability(array);
```

#### 咒语系统

```javascript
// 创建咒语
var spell = magic.createSpell('火球术');
spell.difficulty = 2;
magic.configureSpellPurifying(spell, lvMagic.Element.FIRE, 0.9);
magic.configureSpellInfusing(spell, lvMagic.Threshold.T3);

// 执行施法
var result = magic.castSpell(spell, array);
```

#### 咒语书系统

```javascript
// 创建咒语书
var spellBook = magic.createSpellBook();

// 添加咒语
spellBook.add(spell);

// 获取咒语
var fireball = spellBook.get('火球术');
```

## 施法流程

### 四阶段模型

```
开模 (Molding) → 提纯 (Purifying) → 灌注 (Infusing) → 释放 (Releasing)
```

1. **开模**：定义法术的基本形态
2. **提纯**：纯化元素属性
3. **灌注**：注入能量达到阈值
4. **释放**：投射到目标

## 示例代码

### 完整示例：施放火球术

```javascript
// 1. 创建魔法系统实例
var magic = lvMagic.createMagic();

// 2. 创建咒语书
var spellBook = magic.createStarterSpellBook();

// 3. 获取火球术
var fireball = spellBook.get('火球术');

// 4. 准备魔法阵
var fireArray = magic.createArray();
magic.addRuneToArray(fireArray, magic.createRationalRune(1, 1, lvMagic.Element.FIRE));
magic.addRuneToArray(fireArray, magic.createRationalRune(1, 1, lvMagic.Element.FIRE));
magic.addRuneToArray(fireArray, magic.createRationalRune(1, 1, lvMagic.Element.FIRE));

// 5. 添加约束
magic.addConstraintToArray(fireArray, lvMagic.ArrayConstraint.CONNECTION, 0, 1);
magic.addConstraintToArray(fireArray, lvMagic.ArrayConstraint.CONNECTION, 1, 2);

// 6. 施放
var result = magic.castSpell(fireball, fireArray);

console.log(result.status); // SUCCESS
console.log(result.effect.finalEffect); // 效果值
```

## 扩展指南

### 添加新咒语

```javascript
Magic.prototype.createCustomSpell = function(name, element, purity, threshold) {
    var spell = this.createSpell(name);
    spell.purifyingElement = element;
    spell.purifyingPurity = purity;
    spell.infusingThreshold = threshold;

    // 配置开模符文
    var seq = this.createRuneSequence();
    seq.add(this.createRationalRune(1, 1, element));
    this.configureSpellMolding(spell, seq);

    return spell;
};
```

# 轰界魔法体系手册

> 本文档整理了轰界世界观中的魔法体系，用于 Lv-00 编程魔法模拟器的开发参考。

---

## 一、核心概念

### 1.1 魔力、魔法与法术的区别

| 概念 | 定义 | 说明 |
|------|------|------|
| **魔力** | 广泛分布在环境中的基础介质 | 不是体内器官分泌物，可由精神力牵引重组 |
| **魔法** | 对介质本质的理解框架 | 理论体系、认知模型 |
| **法术** | 可执行、可复现的流程结果 | 具体的施法流程和技术实现 |

> **关键设定**：法师不存在固定"储魔腺体"，施法消耗的是精神力、注意力和认知负荷。

### 1.2 法师资质三要素

成为法师的核心门槛不是智商，而是：

1. **专注** - 稳定感知施法细节
2. **耐受** - 撑过长周期训练与施法反馈
3. **抗压** - 在外界压力与不确定性中维持判断

---

## 二、施法流程

### 2.1 四阶段流程

```
开模 → 提纯 → 灌注 → 释放
```

| 阶段 | 功能 | 说明 |
|------|------|------|
| **开模** | 外形与结构框架 | 定义法术的基本形态 |
| **提纯** | 元素纯度 | 决定法术的元素属性精度 |
| **灌注** | 能量阈值 | 决定法术的威力等级 |
| **释放** | 落点与稳定 | 决定法术的命中与持续 |

### 2.2 施法咏唱

- **短咏唱**：提升释放速度，但压缩认知细节
- **长咏唱**：提高参数精度，但容易暴露意图

**两类优化路径**：
- **真言式缩写** - 理性压缩
- **形容式加密** - 叙述映射

---

## 三、元素体系

### 3.1 四基础元素

| 元素 | 特性 | 优势 | 劣势 |
|------|------|------|------|
| **火** | 释放与热效应 | 入门快、输出直观 | 稳定控制困难 |
| **水** | 流动与相态调节 | 防护、救援、团队支持 | 被误解为输出不足 |
| **风** | 运动与压差 | 机动、切割、远程干涉 | 容错偏低 |
| **土** | 结构与承载 | 防线、构型能力 | 施法负担重 |

**虚质 vs 实质**：
- 虚质：火、风 - 施法压力低、上手快、稳定性弱
- 实质：水、土 - 施法负担高、结构表现稳定

### 3.2 复合体系

| 复合系 | 组成 | 特性 |
|--------|------|------|
| **冰系** | 水+风 | 低温与结构锁定 |
| **泥沼系** | 水+土 | 地形束缚 |
| **砂尘系** | 风+土 | 磨损遮断 |
| **云雾系** | 水+风 | 感知扰动 |
| **爆炸系** | 火+风 | 压力壳体与触发窗口 |
| **金属系** | 土+火 | 材料性质改写与结构工程 |

### 3.3 天灾体系

**判定标准**：极难掌控、试错成本过高、失手后果外溢

| 天灾系 | 特性 | 风险 |
|--------|------|------|
| **熔岩系** | 热场扩散 | 对施法者同样危险 |
| **蒸汽系** | 封闭空间杀伤 | 敌我难分 |
| **陨石系** | 轨迹误差敏感 | 误伤放大 |
| **镭射系** | 穿透与偏转 | 误伤风险 |

## 四、第五元素与以太

### 4.1 以太框架

两条主轴：
- **无属性体系** - 省略单元素提纯、兼容高但效应分散
- **操作系** - 直接以精神力作用于向量、振动、搬运、感知

**优势**：泛用与灵活
**风险**：毒化、反噬、高认知负荷

### 5.1 高阶逻辑体系

| 体系 | 特性 | 限制 |
|------|------|------|
| **因果系** | 条件链重排 | 反噬风险高 |
| **时间系** | 局部加速/减速/回溯 | 需代价与寄托物 |

### 5.2 契约术

## 六、施法器具

### 6.1 法杖

- **定义**：施法外设，不是力量本体
- **功能**：精神力汇聚与导流，提升一致性与容错率
- **材质**：木、金属、骨、扇形等均可

### 6.2 魔法阵

- **本质**：公式图形化
- **作用**：前置压缩步骤，降低实时施法负担
- **类型**：
  - 通用型 - 追求泛化
  - 专用型 - 追求性能与保密
  - 符文 - 极限压缩
  - 立体魔法阵 - 并行演算放大复杂度

### 6.3 魔石

- **功能**：储魔介质
- **依赖**：材料纯度、切面结构、折射路径
- **风险**：加工难度高、成本高、失稳爆裂

### 6.4 魔道具

- **构成**：魔石 + 魔法阵 + 操控机制
- **本质**：施法流程的模块化工具
- **风险**：长期依赖会导致主体施法能力退化

---

## 七、魔网与通讯

### 7.1 魔网

- **定义**：历史上施法逸散精神力残渣的集合
- **特性**：近乎全知但不会主动判断的巨大资料池
- **先天术士**：随机接收魔网信息，高波动群体

### 7.2 人造通讯架构

- 据点布设通讯魔法阵
- 节点链路传输精神信息
- 中继型魔术装置扩展距离与容量

## 八、禁术与禁魔

### 8.1 禁术判定三轴

1. **外部代价不可承受** - 引发无法收拾的连锁后果
2. **施术者自损过高** - 脑、神经或施法中枢不可逆损伤
3. **治理不可控** - 诱发扩散性恶行或秩序崩塌

### 8.2 禁魔逻辑

| 类型 | 策略 | 典型做法 |
|------|------|----------|
| **起因破坏** | 让施法条件失效 | 改造环境、领域展开 |
| **过程扰动** | 拆法而不是硬扛 | 拆解、混杂、分离施法四要素 |
| **结果对冲** | 让效果无效化 | 重写、抵消、借力反用 |

## 十八、附魔与魔药

### 18.1 附魔

- **本质**：能力借壳
- **失败常见问题**：效果漂移

### 18.2 魔药

- **作用**：对生理阈值和施法阈值的短时重写
- **风险**：成瘾、耐受、长期损耗
- **态度**：能救命，但不该成为常规解法

## 附录：编程魔法映射建议

基于轰界魔法体系，建议以下编程概念映射：

| 编程概念 | 魔法概念 | 说明 |
|----------|----------|------|
| 变量 | 魔力容器 | 存储魔力值的容器 |
| 函数 | 法术模板 | 可复用的施法流程 |
| 参数 | 施法参数 | 提纯、灌注的具体数值 |
| 循环 | 持续施法 | 维持法术效果 |
| 条件判断 | 施法判定 | 根据条件选择术式 |
| 数组/列表 | 符文序列 | 多个符文的组合 |
| 对象 | 魔法阵结构 | 封装的状态与方法 |
| 异常处理 | 反噬控制 | 处理施法失败 |
| 异步 | 咏唱延迟 | 施法需要时间 |
| 模块 | 魔道具 | 封装的功能单元 |
