## 二、发现的问题及修复情况

### 2.1 Python 层问题（已修复）

#### 问题 1: formula.py 中调用了未导出的 C 函数
**文件**: `python/lv00/formula.py`  
**问题描述**: 
- `validate()` 方法调用了 `formula_validate` 和 `formula_free_error_list`，但这些函数在 C 库中未导出
- `parse()` 方法调用了 `parse_result_get_ast` 和 `parse_result_destroy`，但 `formula_parse` 直接返回 `FormulaNode*`
- `to_graph()` 方法调用了 `formula_to_graph_result_*` 系列函数，这些函数也未导出

**修复方案**:
- `validate()`: 改为基本验证，添加注释说明完整验证需要 C 库支持
- `parse()`: 直接使用 `formula_parse` 返回的指针，使用 `formula_parser_get_last_error` 获取错误
- `to_graph()`: 简化实现，添加 try-except 保护释放操作

**修复状态**: ✅ 已修复

#### 问题 2: engine.py 文件路径编码问题
**文件**: `python/lv00/engine.py`  
**问题描述**: 使用 `.encode('utf-8')` 处理文件路径，在 Windows 上可能无法处理非 UTF-8 路径

**修复方案**: 已使用 `os.fsencode()` 替代（代码中已修复）

**修复状态**: ✅ 已确认正确

#### 问题 3: core.py 中 Point 类的 __hash__ 问题
**文件**: `python/lv00/core.py`  
**问题描述**: 定义了 `__eq__` 后未显式设置 `__hash__`，Python 3 会将其设为 None

**修复方案**: 已显式设置 `__hash__ = None` 并添加注释说明（代码中已修复）

**修复状态**: ✅ 已确认正确
