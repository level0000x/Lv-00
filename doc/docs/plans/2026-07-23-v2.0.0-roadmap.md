## 二、v2.0.0 规划：λ-演算内核集成 + 基础设施补齐

### 总目标

在推理层集成 λ-演算内核，使几何构造可以用 λ-项表达，建立"构造即证明"的基础设施。同时补齐设计文档中标注为高优先级的基础设施缺口。

### 架构决策

**λ-演算的几何表示**（按设计文档 8.1 节）：
- `λx.M` → 标准 Lv-00 函数块
- β-归约 → 重写规则（模式匹配 + 端口重定向）
- α-等价 → 自然满足（端口连接图相同）
- 变量捕获消解 → `parent_block_id` 三字段 O(1) 判定

---

## 三、分阶段任务

### 阶段 A：端口作用域系统完整化（v2.0.0-a）

补齐 `GeomNode` 三字段的生命周期管理，使端口继承规则可运作。

#### A1: 修复 GeomNode 数据结构

**文件**: `core/include/lv/constraint_graph.h`、`core/src/layer3_geometry/constraint_graph/graph_node.c`

- 确保 `GeomNode` 的 `namespace_depth`、`parent_block_id`、`is_formal_param` 三字段在所有创建路径上正确初始化
- 图编辑 API（AddNode、AddConstraint）内部维护三字段不变量
- 调试模式一致性断言：验证复制后 `parent_block_id` 指向有效块

#### A2: 实现 β-归约端口继承规则

**文件**: `core/src/layer4_reasoning/`（新增 `rewrite/beta_reduce.c`）

- 实现 `beta_reduce_match()`：检测函数块输入端口连接到实参输出端口的模式
- 实现 `beta_reduce_apply()`：复制内部子图，按三字段规则重定向连线
  - 情况 A：形式参数引用 → 重定向到实参输出
  - 情况 B：自由变量引用 → 保持原目标不变
  - 情况 C：内部局部引用 → 重映射到复制件对应新端口
- 实现 `beta_reduce()` 顶层函数

#### A3: λ-项数据结构

**文件**: `core/include/lv/lambda_term.h`（新增）

- 定义 `LvLambdaTerm` 类型（Var/Abs/App）
- 定义 `LvLambdaApp` 结构
- API：`lv_lambda_create_var`、`lv_lambda_create_abs`、`lv_lambda_create_app`、`lv_lambda_destroy`

#### A4: 惰性复制（写时优化）

**文件**: `core/src/layer3_geometry/node_deep_copy.c`（修改）

- 实现写时复制机制：复制操作不立即深拷贝整个子图，只在被修改时才真正复制被修改的节点和连线
- 安全共享条件：子图内不包含形式参数引用

---

### 阶段 B：信任颜色系统完整化（v2.0.0-b）

补齐设计文档的多色标记系统。

#### B1: 扩展 TrustColor 枚举

**文件**: `core/include/lv/lv.h`、`core/include/lv/constraint_graph.h`

- 在现有 `TrustColor` 基础上增加子类型
  ```c
  typedef enum {
      COLOR_GREEN,           // 全构造
      COLOR_BLUE_UNEXPLORED, // 未探索
      COLOR_BLUE_EXCEEDED,   // 资源受限
      COLOR_BLUE_OUT_OF_SCOPE, // 超出范围
      COLOR_YELLOW,          // 条件性不可构造
      COLOR_LIGHT_ORANGE_ORACLE, // 非构造性 oracle（实心端口）
      COLOR_LIGHT_ORANGE_EXPLOSION, // 爆炸原理（虚线箭头）
      COLOR_AMBER,           // 数值假设
      COLOR_DEEP_ORANGE      // 叠加
  } TrustColor;
  ```

#### B2: 着色传播逻辑

**文件**: `core/src/layer4_reasoning/engine/engine.c`（修改）
- 沿依赖关系向下游单向传播着色标记
- 实现颜色叠加规则（浅橙+橙黄→深橙）
- 实现着色报告 API

#### B3: 数值假设逃逸出口

**文件**: `core/src/layer3_geometry/`（修改）
- 在位数熔断点实现"永久降级为数值假设"选项
- 存储数值假设声明文本和精度阈值
- 下游节点自动继承橙黄色标记

### 阶段 C：λ-演算核心实现（v2.0.0-c）

在设计文档 8.1 节技术路线基础上实现 λ-演算的几何编码。

#### C1: λ-项 → 约束图编译

**文件**: `core/src/layer4_reasoning/`（新增 `lambda/lambda_to_graph.c`）
- `lv_lambda_to_graph()`：将 λ-项编译为约束图函数块
- `lv_graph_to_lambda()`：将约束图函数块还原为 λ-项（用于验证）

#### C2: β-归约重写规则注册

**文件**: `core/src/layer4_reasoning/rewrite/`（修改）
- 将 β-归约注册为标准重写规则
- 与现有重写引擎协作：β-归约优先 → 其他规则跟进

#### C3: 测试用例：Church 编码

**文件**: `test/c/test_lambda_church.c`（新增）
- Church 数字编码：`λf.λx.f x`、`λf.λx.f(f x)` 等
- Church 算术：加法、乘法、乘幂
- 验证 (2^2) 完整归约迹

#### C4: 测试用例：Y 组合子

**文件**: `test/c/test_lambda_church.c`（已包含）
- Y 组合子单步展开：`Y F → F (Y F)`（`test_y_combinator_step`）
- Y 组合子多步归约：`Y F 3` 至范式（6 = 3!）（`test_y_combinator_factorial`）
- 验证深层递归展开中共享子图引用一致性
- Y 组合子测试已整合在 Church 编码测试文件中，作为统一 λ-演算端到端测试的一部分。

#### C5: 长期稳定性测试

**文件**: `test/c/test_lambda_church.c`（已包含）
- Church 数字多次运算循环执行（测试函数内已包含多次调用）
- 监控内存使用和节点计数（通过 ConstraintGraph 结构体字段追踪）
- 调试模式引用计数校验（依赖编译时断言和运行时检查）
- 稳定性验证已整合在 Church 编码测试中，确保长时间运行的内存安全。
