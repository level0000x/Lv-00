# Lv-00 八大推理策略形式化定义

**版本**: v3.4-academic  
**状态**: 规范文档

---

## 1. 概述

本文档形式化定义 Lv-00 几何元语言系统的八大核心推理策略。这些策略构成证明引擎的基础推理规则集，支持自动化证明搜索和交互式证明构造。

### 1.1 策略分类

| 类别 | 策略 | 逻辑类型 |
|------|------|----------|
| 结构规则 | 引入 (Intro) | 构造性 |
| 结构规则 | 消去 (Elim) | 分析性 |
| 等价变换 | 重写 (Rewrite) | 保真性 |
| 归纳原理 | 归纳 (Induction) | 生成性 |
| 矛盾推理 | 矛盾 (Contradiction) | 非构造性 |
| 分情况推理 | 情况分析 (Case-Split) | 析取性 |
| 量化推理 | 泛化 (Generalize) | 全称引入 |
| 量化推理 | 特化 (Specialize) | 全称消去 |

## 2. 引入规则 (Introduction Rules)

### 2.1 形式化定义

```
┌─────────────────────────────────────────────────────────────┐
│                    引入规则 (RULE_INTRO)                      │
├─────────────────────────────────────────────────────────────┤
│  语法: intro <connective>                                    │
│                                                              │
│  合取引入 (∧-intro):                                         │
│    Γ ⊢ A    Γ ⊢ B                                           │
│    ─────────────────                                         │
│    Γ ⊢ A ∧ B                                                 │
│                                                              │
│  蕴含引入 (→-intro):                                         │
│    Γ, A ⊢ B                                                  │
│    ─────────────                                             │
│    Γ ⊢ A → B                                                 │
│                                                              │
│  全称引入 (∀-intro):                                         │
│    Γ ⊢ P(x)    (x 不在 Γ 中自由出现)                         │
│    ────────────────────────────                              │
│    Γ ⊢ ∀x. P(x)                                              │
│                                                              │
│  存在引入 (∃-intro):                                         │
│    Γ ⊢ P(t)                                                  │
│    ─────────────                                             │
│    Γ ⊢ ∃x. P(x)                                              │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 适用条件

- **合取引入**: 所有子目标已证明
- **蕴含引入**: 当前上下文中可假设前件
- **全称引入**: 变量不在假设中自由出现
- **存在引入**: 存在见证项 `t`

### 2.3 几何应用示例

```
命题: 三角形 ABC 是等腰三角形 ∧ 底角相等

策略应用:
  1. intro-and
     → 生成子目标:
       - 子目标1: 证明 AB = AC
       - 子目标2: 证明 ∠B = ∠C
```

## 3. 消去规则 (Elimination Rules)

### 3.1 形式化定义

```
┌─────────────────────────────────────────────────────────────┐
│                    消去规则 (RULE_ELIM)                       │
├─────────────────────────────────────────────────────────────┤
│  语法: elim <hypothesis>                                     │
│                                                              │
│  合取消去 (∧-elim):                                          │
│    Γ ⊢ A ∧ B                                                 │
│    ─────────────                                             │
│    Γ ⊢ A          Γ ⊢ B                                      │
│                                                              │
│  蕴含消去 (→-elim / Modus Ponens):                           │
│    Γ ⊢ A → B    Γ ⊢ A                                        │
│    ───────────────────                                       │
│    Γ ⊢ B                                                      │
│                                                              │
│  全称消去 (∀-elim):                                          │
│    Γ ⊢ ∀x. P(x)                                              │
│    ──────────────                                            │
│    Γ ⊢ P(t)        (任意项 t)                                │
│                                                              │
│  存在消去 (∃-elim):                                          │
│    Γ ⊢ ∃x. P(x)    Γ, P(c) ⊢ Q    (c 新常量)                │
│    ─────────────────────────────                             │
│    Γ ⊢ Q                                                      │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 适用条件

- **合取消去**: 假设中存在合取命题
- **蕴含消去**: 假设中存在蕴含式且前件可证
- **全称消去**: 假设中存在全称量化命题
- **存在消去**: 假设中存在存在量化命题

### 3.3 几何应用示例

```
假设: 三角形 ABC 是等腰三角形 (定义: AB = AC ∧ ∠B = ∠C)

策略应用:
  1. elim-and "ABC是等腰三角形"
     → 提取:
       - 新假设: AB = AC
       - 新假设: ∠B = ∠C
```

## 4. 重写规则 (Rewrite Rules)

### 4.1 形式化定义

```
┌─────────────────────────────────────────────────────────────┐
│                    重写规则 (RULE_REWRITE)                    │
├─────────────────────────────────────────────────────────────┤
│  语法: rewrite <equation> [at <position>]                    │
│                                                              │
│  等式重写:                                                   │
│    Γ ⊢ t₁ = t₂    Γ ⊢ P(t₁)                                 │
│    ────────────────────────                                  │
│    Γ ⊢ P(t₂)                                                 │
│                                                              │
│  定义展开:                                                   │
│    Γ ⊢ D ≡ D'    Γ ⊢ ... D ...                              │
│    ───────────────────────────                               │
│    Γ ⊢ ... D' ...                                            │
│                                                              │
│  定向重写 (从左到右 / 从右到左):                             │
│    rewrite ← : 用右边替换左边                                │
│    rewrite → : 用左边替换右边                                │
└─────────────────────────────────────────────────────────────┘
```

### 4.2 适用条件

- 存在等式假设或定义
- 目标表达式包含可匹配的子项
- 重写后表达式更简单或更接近目标

### 4.3 几何应用示例

```
假设: AB = CD
目标: 证明 AB + EF = CD + EF

策略应用:
  1. rewrite "AB = CD" at "AB + EF"
     → 替换 AB 为 CD
     → 新目标: CD + EF = CD + EF (自反性)
```

## 5. 归纳规则 (Induction Rules)

### 5.1 形式化定义

```
┌─────────────────────────────────────────────────────────────┐
│                    归纳规则 (RULE_INDUCTION)                  │
├─────────────────────────────────────────────────────────────┤
│  语法: induction <variable> [on <structure>]                 │
│                                                              │
│  自然数归纳:                                                 │
│    Γ ⊢ P(0)           (基础情况)                             │
│    Γ, P(n) ⊢ P(S(n))  (归纳步骤)                             │
│    ───────────────────────────                               │
│    Γ ⊢ ∀n. P(n)                                              │
│                                                              │
│  结构归纳 (列表):                                            │
│    Γ ⊢ P([])                 (空列表)                        │
│    Γ, P(xs) ⊢ P(x :: xs)     (构造情况)                      │
│    ───────────────────────────                               │
│    Γ ⊢ ∀xs. P(xs)                                            │
│                                                              │
│  几何归纳 (维度/复杂度):                                     │
│    Γ ⊢ P(0维)                                                │
│    Γ, P(n维) ⊢ P((n+1)维)                                    │
│    ───────────────────────────                               │
│    Γ ⊢ ∀n. P(n维)                                            │
└─────────────────────────────────────────────────────────────┘
```

### 5.2 适用条件

- 目标是全称量化命题
- 存在良基的归纳结构
- 归纳假设足够强

### 5.3 几何应用示例

```
命题: ∀n. 正 n 边形的内角和 = (n-2) × 180°

策略应用:
  1. induction n
     → 生成子目标:
       - 基础情况: n=3 (三角形) 内角和 = 180°
       - 归纳步骤: 假设 n 边形成立，证明 (n+1) 边形
```

## 6. 矛盾规则 (Contradiction Rules)

### 6.1 形式化定义

```
┌─────────────────────────────────────────────────────────────┐
│                  矛盾规则 (RULE_CONTRADICTION)                │
├─────────────────────────────────────────────────────────────┤
│  语法: contradiction | ex_falso                              │
│                                                              │
│  爆炸原理 (Ex Falso Quodlibet):                              │
│    Γ ⊢ ⊥                                                     │
│    ────────                                                  │
│    Γ ⊢ A        (任意命题 A)                                 │
│                                                              │
│  反证法 (Proof by Contradiction):                            │
│    Γ, ¬A ⊢ ⊥                                                 │
│    ──────────                                                │
│    Γ ⊢ A                                                      │
│                                                              │
│  矛盾检测:                                                   │
│    Γ ⊢ A    Γ ⊢ ¬A                                           │
│    ───────────────                                           │
│    Γ ⊢ ⊥                                                      │
└─────────────────────────────────────────────────────────────┘
```

### 6.2 适用条件

- **爆炸原理**: 已推导出矛盾
- **反证法**: 目标否定可假设
- **矛盾检测**: 存在互斥命题对

### 6.3 作用域限制 (v3.4-academic 整改)

```
┌─────────────────────────────────────────────────────────────┐
│  【重要】反证作用域收束                                      │
├─────────────────────────────────────────────────────────────┤
│  局部矛盾不得推出全局任意命题:                               │
│                                                              │
│    scope S = begin_assumption(¬P)                            │
│      ... 推导出 ⊥ ...                                        │
│      ex_falso_scoped Q in S  → Q 仅在 S 内有效               │
│    end_assumption(S)                                         │
│                                                              │
│  全局命题检查:                                               │
│    proof_has_global_proposition(nav, Q) → false             │
│    (局部推出的 Q 不在全局上下文中)                           │
└─────────────────────────────────────────────────────────────┘
```

### 6.4 几何应用示例

```
命题: 不存在最大的素数

策略应用:
  1. assume ¬P (假设存在最大素数 p)
  2. ... 构造 p! + 1 ...
  3. derive ⊥ (p! + 1 大于 p 且不能被任何素数整除)
  4. contradiction
     → 结论: 存在无穷多个素数
```

## 7. 情况分析规则 (Case-Split Rules)

### 7.1 形式化定义

```
┌─────────────────────────────────────────────────────────────┐
│                  情况分析规则 (RULE_CASE_SPLIT)               │
├─────────────────────────────────────────────────────────────┤
│  语法: cases <disjunction> | split <condition>               │
│                                                              │
│  析取情况分析:                                               │
│    Γ ⊢ A ∨ B    Γ, A ⊢ C    Γ, B ⊢ C                        │
│    ─────────────────────────────────                        │
│    Γ ⊢ C                                                      │
│                                                              │
│  条件情况分析:                                               │
│    Γ, P ⊢ Q    Γ, ¬P ⊢ Q                                     │
│    ───────────────────────                                   │
│    Γ ⊢ Q                                                      │
│                                                              │
│  穷尽情况分析 (几何):                                        │
│    点 P 在直线 L 上 ∨ 点 P 不在直线 L 上                     │
│    角 ∠A 是锐角 ∨ ∠A 是直角 ∨ ∠A 是钝角                      │
└─────────────────────────────────────────────────────────────┘
```

### 7.2 适用条件

- 存在析取假设
- 可找到完备划分条件
- 所有情况可独立证明

### 7.3 几何应用示例

```
命题: 三角形至少有一个角 ≥ 60°

策略应用:
  1. cases "∠A ≥ 60° ∨ ∠A < 60°"
     → 情况1: ∠A ≥ 60° (直接成立)
     → 情况2: ∠A < 60°
        → 子目标: 证明 ∠B ≥ 60° ∨ ∠C ≥ 60°
        → 使用: ∠A + ∠B + ∠C = 180°
```

## 8. 泛化规则 (Generalization Rules)

### 8.1 形式化定义

```
┌─────────────────────────────────────────────────────────────┐
│                   泛化规则 (RULE_GENERALIZE)                  │
├─────────────────────────────────────────────────────────────┤
│  语法: generalize <term> to <variable>                       │
│                                                              │
│  全称泛化:                                                   │
│    Γ ⊢ P(t)        (t 是任意项)                              │
│    ───────────                                              │
│    Γ ⊢ ∀x. P(x)     (x 不在 Γ 中自由出现)                    │
│                                                              │
│  抽象泛化:                                                   │
│    Γ ⊢ ... 具体值 ...                                        │
│    ───────────────────                                       │
│    Γ ⊢ ... 抽象变量 ...                                      │
│                                                              │
│  几何泛化:                                                   │
│    证明对特定点成立 → 证明对任意点成立                       │
└─────────────────────────────────────────────────────────────┘
```

### 8.2 适用条件

- 证明不依赖于具体项
- 变量捕获检查通过
- 泛化后命题有意义

### 8.3 几何应用示例

```
已证: 点 M 是 AB 的中点 → AM = MB

策略应用:
  1. generalize "AB" to "线段 s"
     → 新命题: ∀线段 s. M 是 s 的中点 → s 的两半相等
```

```
┌─────────────────────────────────────────────────────────────┐
│                   特化规则 (RULE_SPECIALIZE)                  │
├─────────────────────────────────────────────────────────────┤
│  语法: specialize <universal> with <term>                    │
│                                                              │
│  全称特化:                                                   │
│    Γ ⊢ ∀x. P(x)                                              │
│    ────────────                                              │
│    Γ ⊢ P(t)        (任意项 t)                                │
│                                                              │
│  实例化:                                                     │
│    Γ ⊢ ∀三角形 T. 内角和 = 180°                              │
│    ─────────────────────────────────                        │
│    Γ ⊢ 三角形 ABC 的内角和 = 180°                            │
│                                                              │
│  几何特化:                                                   │
│    定理应用: 将通用定理应用到具体图形                        │
└─────────────────────────────────────────────────────────────┘
```

### 9.2 适用条件

- 存在全称量化假设或定理
- 有具体的实例化项
- 实例化后类型匹配

### 9.3 几何应用示例

```
定理: ∀三角形 T. 勾股定理 (直角三角形)

策略应用:
  1. specialize "勾股定理" with "三角形 ABC (直角在 C)"
     → 得到: AB² = AC² + BC²
```

## 10. 策略优先级与搜索

### 10.1 默认优先级

| 优先级 | 策略 | 理由 |
|--------|------|------|
| 1 (最高) | 矛盾 | 终止证明 |
| 2 | 消去 | 简化假设 |
| 3 | 重写 | 简化目标 |
| 4 | 引入 | 分解目标 |
| 5 | 特化 | 应用定理 |
| 6 | 情况分析 | 分支搜索 |
| 7 | 归纳 | 生成子目标 |
| 8 (最低) | 泛化 | 强化目标 |

### 10.2 搜索策略

```
┌─────────────────────────────────────────────────────────────┐
│                      搜索策略配置                             │
├─────────────────────────────────────────────────────────────┤
│  SEARCH_BEST_FIRST:                                         │
│    - 按权重排序规则                                          │
│    - 优先尝试高优先级规则                                    │
│    - 适合快速找到证明                                        │
│                                                              │
│  SEARCH_DEPTH_FIRST:                                        │
│    - 深度优先探索                                            │
│    - 可能快速找到深证明                                      │

│                                                              │
│  SEARCH_BREADTH_FIRST:                                      │
│    - 广度优先探索                                            │
│    - 保证找到最短证明                                        │

│                                                              │
│  SEARCH_ITERATIVE_DEEPENING:                                │
│    - 迭代加深搜索                                            │
│    - 平衡深度和广度                                          │
│    - 适合复杂证明                                            │
└─────────────────────────────────────────────────────────────┘
```
