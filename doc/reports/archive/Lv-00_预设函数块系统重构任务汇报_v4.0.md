## 4. 代码风格改进

### 4.1 标准化改进

| 改进项 | 原状态 | 改进后 |
|-------|-------|-------|
| 命名规范 | 部分不一致 | 统一使用 `func_block_preset_` 前缀 |

| 常量定义 | 魔术数字 | 统一命名常量 |

### 4.2 风险消除

| 风险类型 | 处理措施 |
|---------|---------|
| 空指针解引用 | 所有公共API入口检查NULL参数 |

### 5.1 几何构造类 (15个)

| 预设名称 | 输入 | 输出 | 数学定义 | 性质 |
|---------|------|------|---------|------|

| circumcenter | 3点 | 1点 | \|OA\|=\|OB\|=\|OC\| | 确定、连续、构造 |
| orthocenter | 3点 | 1点 | 三条高的交点 | 确定、连续、构造 |
| incenter | 3点 | 1点 | I = (aA+bB+cC)/(a+b+c) | 确定、连续、构造 |
| excenter | 3点 | 1点 | I_A = (-aA+bB+cC)/(-a+b+c) | 确定、连续、构造 |

## 6. API 使用示例

### 6.1 基础使用

```c
#include "lv00.h"

/* 初始化预设库 */
func_block_preset_library_init();

/* 查找预设 */
if (func_block_preset_exists("midpoint")) {
    const PresetMetadata *meta = func_block_preset_get_metadata("midpoint");
    printf("%s: %s\n", meta->name, meta->description);
}

/* 实例化预设 */
FuncBlock *fb;
int inputs[] = {node_a_id, node_b_id};
InstantiateResult result = func_block_preset_instantiate(
    "midpoint", inputs, 2, graph, &fb);

/* 清理 */
func_block_preset_library_cleanup();
```

### 6.2 高级使用

```c
/* 验证参数类型 */
if (func_block_preset_validate_types("midpoint", nodes, 2, NULL)) {
    /* 类型匹配，继续实例化 */
}

/* 生成文档 */
char doc[4096];
func_block_preset_generate_doc("midpoint", doc, sizeof(doc));

/* 获取逆操作 */
const char *inverse = func_block_preset_get_inverse("rotation");
```
