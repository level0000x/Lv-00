### 2.2 新增模块

#### preset_func_blocks.py（预设函数块模块）

创建了全新的预设函数块模块，提供理论数学研究中常用的几何构造：

**基础几何构造**：
- `midpoint` - 中点构造
- `perpendicular_bisector` - 垂直平分线
- `angle_bisector` - 角平分线
- `line_intersection` - 线段交点
- `perpendicular_line` - 垂线
- `parallel_line` - 平行线

**圆相关构造**：
- `circle_center` - 圆心（由三点确定）
- `circle_line_intersection` - 圆与直线交点
- `tangent_line` - 切线

**三角形构造**：
- `centroid` - 重心
- `orthocenter` - 垂心
- `circumcenter` - 外心
- `incenter` - 内心

**多边形构造**：
- `regular_polygon` - 正多边形

```
    ├── create_incenter()
    └── create_orthocenter()
```

### 4.2 确定性保证

每个预设函数块都明确标注了确定性级别：

| 级别 | 含义 | 示例 |
|------|------|------|
| ALWAYS_UNIQUE | 总是唯一解 | 中点、重心 |
| CONDITIONALLY_UNIQUE | 条件唯一解 | 线段交点（不平行时） |
| MULTIPLE_SOLUTIONS | 可能多解 | 圆与直线交点 |

### 4.3 前置条件检查

每个预设函数块的创建函数都包含前置条件验证：

```python
def create_midpoint(graph, p1, p2):
    # 验证输入点不同
    if p1.x == p2.x and p1.y == p2.y:
        raise ValueError("两点重合，无法计算中点")
    ...
```

## 六、使用示例

### 6.1 基础使用

```python
from lv00 import Graph
from lv00.preset_func_blocks import create_midpoint, create_centroid

# 创建约束图
g = Graph()

# 添加点
a = g.add_point(0, 0)
b = g.add_point(2, 0)
c = g.add_point(1, 2)

# 使用预设函数块
mid = create_midpoint(g, a, b)  # 中点
centroid = create_centroid(g, a, b, c)  # 重心
```

### 6.2 查询预设信息

```python
from lv00.preset_func_blocks import get_preset_info, list_all_presets

# 列出所有预设
print(list_all_presets())

# 获取详细信息
print(get_preset_info("midpoint"))
```

### 6.3 使用引擎便捷方法

```python
from lv00 import Engine

with Engine() as engine:
    engine.load_module("geometry.lv00")
    
    # 安全求解
    status, msg = engine.safe_solve()
    if status != 0:
        print(f"求解失败: {msg}")
    
    # 获取统计信息
    stats = engine.get_statistics()
    print(f"引擎状态: {stats}")
```
