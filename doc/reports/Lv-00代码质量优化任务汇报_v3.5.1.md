#### M-02: 路径遍历安全漏洞修复
**位置**: `module/python/lv00/proof_extras.py`

**问题描述**: `export_json()` 和 `export_dot()` 方法未验证文件路径，可能导致路径遍历攻击。

**修复内容**:
1. 添加 `_validate_filepath()` 工具函数
2. 在导出方法中调用路径验证
3. 限制路径必须在当前工作目录或用户主目录下

**修复后代码**:
```python
def _validate_filepath(filepath: str, must_exist: bool = False) -> Path:
    """验证文件路径的安全性。"""
    path = Path(filepath).resolve()
    
    # 检查路径遍历
    try:
        path.relative_to(Path.cwd())
    except ValueError:
        home = Path.home()
        try:
            path.relative_to(home)
        except ValueError:
            raise ValueError(f"路径不安全: {filepath}")
    
    return path

def export_json(self, filepath: str) -> bool:
    # [代码质量修复 M-02] 添加路径验证
    validated_path = _validate_filepath(filepath)
    return _lib.proof_search_tree_export_json(self._ptr, str(validated_path).encode('utf-8'))
```

**位置**: `module/python/lv00/interactive_geo.py`

**新增功能**:
1. `throttle(min_interval)` - 节流装饰器，限制调用频率（默认 60 FPS）
2. `debounce(wait)` - 防抖装饰器，延迟执行并重新计时

**使用示例**:
```python

@throttle(0.016)  # 限制为 60 FPS
def on_drag_move(x, y):
    update_position(x, y)

@debounce(0.3)  # 300ms 防抖
def on_search(query):
    perform_search(query)
```
