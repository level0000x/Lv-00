### 3.2 流式事件缓冲区优化 (P1 - HIGH)

**问题**: 原实现使用 `array.shift()` 从数组头部删除元素，这是 O(n) 操作，高频事件下性能差。

**修改文件**: `web-gui/src/services/streamManager.ts`

**优化方案**: 使用环形缓冲区替代数组移位

**修改前**:
```typescript
private addEvent(event: UnifiedStreamEvent): void {
  this.eventBuffer.push(event);
  if (this.eventBuffer.length > this.config.eventBufferSize) {
    this.eventBuffer.shift(); // O(n) 操作
  }
}
```

**修改后**:
```typescript
private addEvent(event: UnifiedStreamEvent): void {
  const capacity = this.config.eventBufferSize;

  // 环形缓冲区写入
  if (this.bufferSize < capacity) {
    this.eventBuffer.push(event);
    this.bufferSize++;
  } else {
    this.eventBuffer[this.bufferHead] = event;
    this.bufferHead = (this.bufferHead + 1) % capacity;
  }
}
```

**新增API**:
- `getBufferedEvents()`: 获取缓冲区中的所有事件（按时间顺序）
- `clearBuffer()`: 清空缓冲区
