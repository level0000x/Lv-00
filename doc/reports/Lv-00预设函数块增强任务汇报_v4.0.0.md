## 1. 任务概述

### 1.1 任务目标

本次任务旨在对 Lv-00 几何元编程库的预设函数块系统进行全面增强，包括：

1. **增加预设函数块**：新增多个几何构造函数块，覆盖更广泛的几何构造需求
2. **代码模块化标准化**：重构代码架构，实现高内聚低耦合的模块化设计
3. **完善中文注释**：为所有公共 API 提供完整的中文文档
4. **代码风格统一**：遵循 PEP 8 和项目编码规范，消除代码风格问题
5. **向后兼容性**：确保现有代码不受影响

### 1.2 执行策略

- **评估后改动**：对需要大量改动的代码进行评估后再实施
- **局部最优解**：在条件满足的情况下，追求代码的局部最优解
- **人性化设计**：需要的功能进行合并、重写或添加
- **零风险原则**：不留下任何代码风格或质量风险

## 2. 架构重构

### 2.1 原架构（v3.x）

```
lv00/
├── preset_func_blocks.py    # 主入口（重新导出层）
├── preset_basic.py          # 基础构造 + 注册表
├── preset_analysis.py       # 三角形构造
├── preset_algebra.py        # 变换构造
└── preset_topology.py       # 多边形构造
```

**问题分析**：
- 模块划分粒度不均，preset_basic.py 职责过重
- 缺乏统一的参数规格定义
- 输出格式不明确
- 扩展性受限

### 2.2 新架构（v4.x）

```
lv00/
├── preset_blocks/           # 新预设函数块包
│   ├── __init__.py         # 包入口，统一导出
│   ├── base.py             # 基础架构（枚举、数据类、注册表）
│   ├── geometry.py         # 几何构造（基础、圆、三角形、多边形）
│   ├── algebra.py          # 代数变换
│   └── advanced.py         # 高级构造（调和分割、极线极点等）
├── preset_func_blocks.py   # 向后兼容层（已弃用警告）
└── __init__.py             # 主包入口（更新版本号）
```

**架构优势**：
- **单一职责**：每个模块职责清晰明确
- **可扩展性**：易于添加新的函数块类别
- **类型安全**：完整的类型注解支持
- **文档完善**：统一的中文文档规范

## 4. 核心架构组件

### 4.1 枚举类型（base.py）

```python
class PresetCategory(Enum):
    """预设函数块分类枚举"""
    BASIC = auto()           # 基础几何构造
    CIRCLE = auto()          # 圆相关构造
    TRIANGLE = auto()        # 三角形构造
    POLYGON = auto()         # 多边形构造
    TRANSFORMATION = auto()  # 几何变换
    ALGEBRA = auto()         # 代数运算
    TOPOLOGY = auto()        # 拓扑分析
    ANALYSIS = auto()        # 数学分析
    LOGIC = auto()           # 逻辑推导
    ADVANCED = auto()        # 高级构造

class DeterminismLevel(Enum):
    """确定性级别枚举"""
    ALWAYS_UNIQUE = auto()       # 总是唯一解
    CONDITIONALLY_UNIQUE = auto() # 条件唯一解
    MULTIPLE_SOLUTIONS = auto()   # 多解情况

class OutputFormat(Enum):
    """输出格式枚举"""
    POINT = auto()       # 点坐标
    LINE = auto()        # 直线
    SEGMENT = auto()     # 线段
    CIRCLE = auto()      # 圆
    SCALAR = auto()      # 标量值
    VECTOR = auto()      # 向量
    BOOLEAN = auto()     # 布尔值
    COLLECTION = auto()  # 集合
```

### 4.2 数据类（base.py）

```python
@dataclass(frozen=True)
class ParamSpec:
    """参数规格数据类"""
    name: str           # 参数名称
    chinese_name: str   # 中文名称
    description: str    # 描述
    param_type: str     # 参数类型
    required: bool = True      # 是否必需
    default_value: Any = None  # 默认值

@dataclass(frozen=True)
class OutputSpec:
    """输出规格数据类"""
    name: str           # 输出名称
    chinese_name: str   # 中文名称
    description: str    # 描述
    output_format: OutputFormat  # 输出格式
    count: int = 1      # 输出数量

@dataclass
class FuncBlockSpec:
    """函数块规格说明数据类"""
    name: str                    # 函数块名称
    chinese_name: str            # 中文名称
    category: PresetCategory     # 所属分类
    description: str             # 详细描述
    params: List[ParamSpec]      # 输入参数列表
    outputs: List[OutputSpec]    # 输出规格列表
    determinism: DeterminismLevel  # 确定性级别
    preconditions: List[str]     # 前置条件
    mathematical_definition: str # 数学定义
    example_usage: str           # 使用示例
    notes: str                   # 注意事项
    version: str = "4.0.0"       # 版本号
    author: str = "Lv-00 开发团队"  # 作者
```

## 9. 使用示例

### 9.1 基础使用

```python
from lv00 import Graph
from lv00.preset_blocks import create_midpoint, create_centroid

# 创建约束图
g = Graph()

# 添加点
a = g.add_point(0, 0)
b = g.add_point(2, 0)
c = g.add_point(1, 2)

# 计算中点
midpoint = create_midpoint(g, a, b)
print(f"中点: {midpoint}")  # Point(1, 0)

# 计算重心
centroid = create_centroid(g, a, b, c)
print(f"重心: {centroid}")  # Point(1, 2/3)
```

### 9.2 变换使用

```python
from lv00.preset_blocks import create_reflection, create_rotation
import math

# 反射变换
p = g.add_point(1, 2)
p_reflected = create_reflection(g, p, a, b)  # 关于 AB 对称

# 旋转变换
center = g.add_point(0, 0)
p_rotated = create_rotation(g, p, center, math.pi / 2)  # 旋转 90°
```
