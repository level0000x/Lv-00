## 一、项目概况

Lv-00 是一个纯 C11 从零自主研发的几何元语言，将几何构造、计算程序、一阶逻辑证明三者统一于同一语法体系。项目采用五层单向依赖架构（v3.3），包含约 550+ 个 C/H 源文件（约 14.3 MB）、80+ 个 Python 文件（约 1.2 MB）、55+ 数学理论预设模块。

### 项目规模统计

| 类别 | 文件数 | 总大小 |
|------|--------|--------|
| C 核心源码 (core/src) | ~250 .c + ~200 .h | ~9.9 MB |
| C 公共头文件 (core/include) | ~180 .h | ~2.4 MB |
| C 测试代码 (test/c) | ~110 .c + 1 .h | ~1.9 MB |
| Python 模块 (module/) | ~60 .py | ~1.2 MB |
| Web 前端 (web/gui) | ~80 .tsx/.ts | - |
| 配置与文档 | ~30 文件 | - |

### 3.2 ARM64 架构检测 Bug [已修复]

lv00.c 中 `__aarch64__` 被错误映射到 "x86_64"，导致 ARM64 平台上返回错误的架构信息。已将 `__aarch64__` 拆分为独立的 #if 分支，正确返回 "aarch64"。

**文件**：core/src/layer2_resource/lv00.c

### 3.3 python-jose 安全风险 [已修复]

module/llm_coding_assistant/requirements.txt 使用已停止维护的 python-jose 库（最后更新 2021 年），存在已知安全问题。已移除 python-jose 和 passlib，替换为项目已使用的 PyJWT>=2.8,<3.0。

**文件**：module/llm_coding_assistant/requirements.txt

### 3.4 互斥锁初始化竞态条件 [已修复]

geometry_config.c 中 ensure_mutex_initialized() 存在经典的 TOCTOU 竞态条件。已将 config_mutex_initialized 声明为 volatile，添加详细的线程安全说明注释。

**文件**：core/src/layer2_resource/geometry_config.c
