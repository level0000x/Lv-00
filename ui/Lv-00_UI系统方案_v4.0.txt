一、总体架构

1.1 六层架构

层级 名称 语言 物理形态 对上层暴露 对下层依赖
L1 裸核引擎 C11 liblv00_core.so C ABI 函数指针 无
L2 编辑控制器 C++17 liblv00_editor.a EditorController 类 L1
L3 多模态投影引擎 C++17 liblv00_scene.a SceneController 类 L2
L4 模态视图组件 TypeScript/C++ 6 个独立组件 React 组件 / Qt Widget L3（数据）
L5 外壳适配器 TypeScript/C++ Qt 应用 / VSCode 插件 可执行文件 L4
L6 共享视觉语言 JSON/CSS 静态资源 颜色/图标/字体定义 无

1.2 数据流向

```
用户操作（任一模态）
    ↓
L4 模态视图捕获事件 → 生成 Command（二进制序列化）
    ↓
L3 SceneController.processCommand() → 转发至 L2
    ↓
L2 EditorController.execute() → 压入撤销栈 → 调用 L1 API
    ↓
L1 执行图操作 → 归一化 → 返回结果 + 增量日志（Delta）
    ↓
L2 将 Delta 追加到环形缓冲区 → 广播给所有订阅的 L3 实例
    ↓
L3 更新内部 SceneState → 重新计算所有模态的投影数据
    ↓
L4 各模态通过轮询 consumeDrawCommands() 获取更新 → 重新渲染
```

关键设计决策：

· 单向数据流：所有修改必须经过 L2 → L1，禁止模态间直接传递数据
· 增量而非全量：L1 只返回变化部分（Delta），减少序列化开销
· 推送+轮询混合：L2 通过回调通知 L3“有新数据”，L3 主动拉取

2.3 L1 实现细节（UI 端需了解的内部机制）

图规范化遍（Normalization）算法：

```
输入: 约束图 G, scope_aware_flag
输出: 规范化的 G, merged_pairs 列表

算法:
1. 遍历所有节点，按符号坐标建立哈希表（key=坐标的规范字符串表示）
2. 对于同一坐标的节点集合 S：
   a. 若所有节点属于同一作用域 (parent_block_id, namespace_depth 相同):
      保留第一个节点，其他节点重定向所有引用到保留节点，删除冗余节点
   b. 若节点跨不同作用域:
      若 scope_aware=true: 记录到 pending_merge_list，不自动执行，等待用户确认
      若 scope_aware=false: 同 a，直接合并
3. 合并后重新编号，更新所有约束的参与者引用
4. 返回 merged_pairs: {{redundant_id, kept_id}, ...}
```

增量日志（Delta）生成机制：

· L1 内部维护一个环形缓冲区，默认容量 10000 条记录
· 每次 lv00_execute() 调用成功后，自动将本次操作产生的所有变更记录追加到缓冲区
· lv00_collect_delta() 从当前读指针开始，返回截至写指针的所有记录，并更新读指针
· 若读指针落后写指针超过 8000 条（80% 容量），L2 应主动拉取，防止溢出

```cpp
struct UndoState {
```

3.5 EditorController 实现细节

execute() 完整流程：

```
EditorController::execute(cmd)
    ↓
1. 将 cmd 压入本地命令历史（用于 UI 显示）
    ↓
2. 若 cmd.type == UNDO: 调用 undo()，直接返回
    ↓
3. 若 cmd.type == REDO: 调用 redo()，直接返回
    ↓
4. 调用 L1: lv00_execute(g, cmd_to_l1)
    ↓
5. 若 L1 返回 success:
   a. 收集 Delta: lv00_collect_delta(g)
   b. 将 Delta 追加到 ringBuffer
   c. 创建 UndoState: { snapshot_id, commands_since_last_snapshot }
   d. 若当前已处于未保存状态（已有未打标的命令），先合并再压栈
   e. 推送通知给所有订阅者: callback(delta)
   f. 返回成功
    ↓
6. 若 L1 返回失败:
   a. 记录错误到 state.last_error
   b. 返回失败，不修改撤销栈
```

undo() 完整流程：

```
EditorController::undo()
    ↓
1. 检查 undoStack.canUndo()
    ↓
2. 从撤销栈弹出 UndoState
    ↓
3. 调用 L1: lv00_restore(g, state.snapshot_id)
    ↓
4. 将 state.commands_since_snapshot 反转后压入 redoStack
    ↓
5. 收集 Delta（L1 恢复后产生的变更） → 推送给订阅者
    ↓
6. 返回成功
```

4.3 M1 核心算法：命中测试（Hit Test）

命中测试用于判断鼠标点击是否落在某个几何对象上。

```cpp
// hit_test.cpp

struct HitResult {
    enum { NONE, NODE, CONSTRAINT, REGION } type;
    uint32_t id;
    float distance;          // 屏幕距离（像素）
};

HitResult SceneController::hitTest(float screenX, float screenY) {
    HitResult best;
    best.type = HitResult::NONE;
    best.distance = INFINITY;
    
    // 1. 将屏幕坐标转为世界坐标
    float worldX = viewport.screenToWorldX(screenX);
    float worldY = viewport.screenToWorldY(screenY);
    
    // 2. 遍历所有节点
    for (const auto& node : state.nodes) {
        float dx = node.coords[0].toDouble() - worldX;
        float dy = node.coords[1].toDouble() - worldY;
        // 世界距离 → 屏幕距离
        float screenDist = sqrt(dx*dx + dy*dy) * viewport.scale;
        
        // 命中阈值：10 像素（可配置）
        if (screenDist < 10.0f && screenDist < best.distance) {
            best.type = HitResult::NODE;
            best.id = node.id;
            best.distance = screenDist;
        }
    }
    
    // 3. 若无命中，检测线段（点到线段距离）
    if (best.type == HitResult::NONE) {
        for (const auto& constraint : state.constraints) {
            if (constraint.type == CONSTR_SEGMENT) {
                // 计算点到线段的屏幕距离
                float dist = pointToSegmentDistance(worldX, worldY, 
                                                     getNode(constraint.p0), 
                                                     getNode(constraint.p1));
                if (dist < 8.0f && dist < best.distance) {
                    best.type = HitResult::CONSTRAINT;
                    best.id = constraint.id;
                    best.distance = dist;
                }
            }
        }
    }
    
    return best;
}
```

```cpp
void SceneController::onMouseDown(float sx, float sy, MouseButton btn) {
    if (btn == MouseButton::LEFT) {
        HitResult hit = hitTest(sx, sy);
        
        if (hit.type == HitResult::NODE) {
            // 如果 Shift 按下，追加到选中列表
            if (isShiftDown()) {
                if (isSelected(hit.id)) {
                    removeFromSelection(hit.id);
                } else {
                    addToSelection(hit.id);
                }
            } else {
                // 普通点击：选中并准备拖拽
                selectNode(hit.id);
                drag.mode = DragMode::DRAGGING;
                drag.draggedNodeId = hit.id;
                drag.startScreenX = sx;
                drag.startScreenY = sy;
                auto node = getNode(hit.id);
                drag.startWorldX = node.coords[0];
                drag.startWorldY = node.coords[1];
            }
        } else {
            // 点击空白处
            if (!isShiftDown()) {
                clearSelection();
            }
            drag.mode = DragMode::SELECTING;
            drag.startScreenX = sx;
            drag.startScreenY = sx;
        }
    } else if (btn == MouseButton::MIDDLE || btn == MouseButton::RIGHT) {
        drag.mode = DragMode::PANNING;
        drag.startScreenX = sx;
        drag.startScreenY = sy;
    }
}

void SceneController::onMouseMove(float sx, float sy) {
    switch (drag.mode) {
        case DragMode::DRAGGING: {
            float dScreenX = sx - drag.startScreenX;
            float dScreenY = sy - drag.startScreenY;
            // 屏幕偏移 → 世界偏移
            float dWorldX = dScreenX / viewport.scale;
            float dWorldY = dScreenY / viewport.scale;
            
            // 累积偏移，但每帧生成临时绘制指令（即时反馈）
            float newWorldX = drag.startWorldX + dWorldX;
            float newWorldY = drag.startWorldY + dWorldY;
            
            // 生成临时绘制指令（亮绿色，半透明）
            DrawCommand temp;
            temp.type = DrawCommand::POINT;
            temp.x1 = newWorldX;
            temp.y1 = newWorldY;
            temp.color = 0x66FFAA88;   // 亮绿色半透明
            temp.radius = 6;
            drawQueue.push_back(temp);
            
            // 显示辅助线（原位置→新位置虚线）
            DrawCommand line;
            line.type = DrawCommand::LINE;
            line.x1 = drag.startWorldX;
            line.y1 = drag.startWorldY;
            line.x2 = newWorldX;
            line.y2 = newWorldY;
            line.color = 0x66FFAA44;
            line.style = DrawCommand::DASHED;
            drawQueue.push_back(line);
            
            break;
        }
        case DragMode::SELECTING: {
            // 绘制选择框
            drawSelectionRect(drag.startScreenX, drag.startScreenY, sx, sy);
            break;
        }
        case DragMode::PANNING: {
            float dX = (sx - drag.startScreenX) / viewport.scale;
            float dY = (sy - drag.startScreenY) / viewport.scale;
            viewport.offsetX += dX;
            viewport.offsetY += dY;
            drag.startScreenX = sx;
            drag.startScreenY = sy;
            break;
        }
    }
}

void SceneController::onMouseUp(float sx, float sy, MouseButton btn) {
    switch (drag.mode) {
        case DragMode::DRAGGING: {
            // 计算最终位置
            float dWorldX = (sx - drag.startScreenX) / viewport.scale;
            float dWorldY = (sy - drag.startScreenY) / viewport.scale;
            float finalX = drag.startWorldX + dWorldX;
            float finalY = drag.startWorldY + dWorldY;
            
            // 构造命令 → 发送给 L2
            Command cmd = Command::makeMoveNode(drag.draggedNodeId, 
                                                Coord::fromDouble(finalX, finalY));
            editor->execute(cmd);
            
            drag.mode = DragMode::NONE;
            break;
        }
        case DragMode::SELECTING: {
            // 计算选择框内的节点
            std::vector<NodeId> hitNodes = getNodesInRect(
                drag.startScreenX, drag.startScreenY, sx, sy
            );
            if (isShiftDown()) {
                // 追加选择
                for (auto id : hitNodes) {
                    if (!isSelected(id)) addToSelection(id);
                }
            } else {
                setSelection(hitNodes);
            }
            drag.mode = DragMode::NONE;
            break;
        }
        case DragMode::PANNING: {
            drag.mode = DragMode::NONE;
            break;
        }
    }
}
```

```cpp
// serialization.cpp
std::string TextSerializer::serialize(const std::vector<Node>& nodes, 
                                       const std::vector<Constraint>& constraints) {
    std::stringstream ss;
    
    // 1. 输出所有点
    for (const auto& node : nodes) {
        if (node.type == NODE_POINT) {
            ss << "point " << node.name << " at (";
            ss << node.coords[0].toString() << ", ";
            ss << node.coords[1].toString() << ")\n";
        }
    }
    
    // 2. 输出所有线段
    for (const auto& c : constraints) {
        if (c.type == CONSTR_SEGMENT) {
            ss << "segment " << c.name << " between ";
            ss << getNode(c.participants[0]).name << " and ";
            ss << getNode(c.participants[1]).name << "\n";
        }
    }
    
    // 3. 输出所有约束
    for (const auto& c : constraints) {
        if (c.type == CONSTR_EQUAL || c.type == CONSTR_PERPENDICULAR || 
            c.type == CONSTR_PARALLEL || c.type == CONSTR_COLLINEAR) {
            ss << "constraint " << constraintTypeToString(c.type) << "(";
            for (int i = 0; i < c.count; i++) {
                if (i > 0) ss << ", ";
                ss << getNode(c.participants[i]).name;
            }
            ss << ")\n";
        }
    }
    
    return ss.str();
}

Command TextSerializer::parseLine(const std::string& line) {
    // 去掉首尾空格
    std::string trimmed = trim(line);
    if (trimmed.empty() || trimmed[0] == '#') return Command::makeNoop();
    
    // 词法分析
    std::vector<std::string> tokens = tokenize(trimmed);
    if (tokens.empty()) return Command::makeNoop();
    
    if (tokens[0] == "point") {
        // point <name> at (<x>, <y>)
        // tokens: [point, name, at, (, x, ,, y, )]
        std::string name = tokens[1];
        double x = std::stod(tokens[4]);
        double y = std::stod(tokens[6]);
        return Command::makeAddNode(name, Coord::fromDouble(x, y));
        
    } else if (tokens[0] == "segment") {
        // segment <name> between <a> and <b>
        std::string name = tokens[1];
        std::string a = tokens[3];
        std::string b = tokens[5];
        return Command::makeAddSegment(name, a, b);
        
    } else if (tokens[0] == "constraint") {
        // constraint <type>(<a>, <b>, ...)
        std::string type = tokens[1];
        // tokens[2] = "("
        std::vector<std::string> params;
        for (size_t i = 3; i < tokens.size(); i++) {
            if (tokens[i] == ")" || tokens[i] == ",") continue;
            params.push_back(tokens[i]);
        }
        return Command::makeAddConstraint(type, params);
    }
    
    return Command::makeNoop();
}
```

```cpp
// dependency_tree.cpp

SceneController::TreeNode SceneController::getDependencyTree() const {
    TreeNode root;
    root.id = "__root__";
    root.label = "证明依赖树";
    root.color = 0xFFFFFF;
    root.status = "root";
    
    // 1. 找到所有定理块和引理块
    std::vector<Proof> proofs = getProofs();
    
    for (const auto& proof : proofs) {
        TreeNode proofNode;
        proofNode.id = "proof_" + std::to_string(proof.id);
        proofNode.label = proof.name;
        proofNode.color = proof.trust_color;
        proofNode.status = proof.is_proved ? "proved" : "pending";
        proofNode.node_id = proof.root_node_id;
        
        // 2. 递归收集依赖
        collectDependencies(proof, proofNode);
        
        root.children.push_back(proofNode);
    }
    
    return root;
}

void SceneController::collectDependencies(const Proof& proof, TreeNode& node) {
    // 遍历 proof 使用的所有引理
    for (const auto& lemma_id : proof.depends_on) {
        const Lemma& lemma = getLemma(lemma_id);
        TreeNode child;
        child.id = "lemma_" + std::to_string(lemma.id);
        child.label = lemma.name;
        child.color = lemma.trust_color;
        child.status = lemma.is_proved ? "proved" : "pending";
        child.node_id = lemma.root_node_id;
        
        // 递归：引理可能依赖其他引理
        collectDependencies(lemma, child);
        
        node.children.push_back(child);
    }
    
    // 3. 遍历 proof 使用的公理
    for (const auto& axiom_id : proof.axiom_refs) {
        const Axiom& axiom = getAxiom(axiom_id);
        TreeNode child;
        child.id = "axiom_" + std::to_string(axiom.id);
        child.label = axiom.name + " (公理)";
        child.color = 0x88CCFF;   // 公理用浅蓝色
        child.status = "assumed";
        child.node_id = 0;
        node.children.push_back(child);
    }
}
```

4.9 M6 拓扑视图：端口提取算法

```cpp
// topology_extractor.cpp

SceneController::TopologyGraph SceneController::getTopologyView() const {
    TopologyGraph result;
    
    // 1. 找到所有函数块节点
    for (const auto& node : state.nodes) {
        if (node.type == NODE_FUNCTION_BLOCK) {
            BlockNode block;
            block.id = node.id;
            block.name = node.name;
            
            // 提取输入端口
            for (const auto& port : node.ports) {
                if (port.direction == PORT_INPUT) {
                    block.inputs.push_back({port.id, port.name, PORT_INPUT, port.connected_to});
                } else {
                    block.outputs.push_back({port.id, port.name, PORT_OUTPUT, port.connected_to});
                }
            }
            
            // 恢复用户拖拽保存的布局位置
            auto itX = topologyLayoutX.find(node.id);
            auto itY = topologyLayoutY.find(node.id);
            if (itX != topologyLayoutX.end() && itY != topologyLayoutY.end()) {
                block.layoutX = itX->second;
                block.layoutY = itY->second;
            } else {
                // 自动布局：简单网格
                block.layoutX = (result.blocks.size() % 4) * 300.0f;
                block.layoutY = (result.blocks.size() / 4) * 150.0f;
            }
            
            result.blocks.push_back(block);
        }
    }
    
    // 2. 提取端口间的连接关系
    for (const auto& constraint : state.constraints) {
        if (constraint.type == CONSTR_CONNECTION) {
            uint32_t from_block = getNode(constraint.from_port).parent_block_id;
            uint32_t to_block = getNode(constraint.to_port).parent_block_id;
            
            TopologyEdge edge;
            edge.from_block = from_block;
            edge.from_port = constraint.from_port;
            edge.to_block = to_block;
            edge.to_port = constraint.to_port;
            result.edges.push_back(edge);
        }
    }
    
    return result;
}
```

```tsx
interface RenderCommand {
    type: 'line' | 'circle' | 'arc' | 'rect' | 'text' | 'point' | 'port' | 'highlight';
    x1: number;
    y1: number;
    x2: number;
    y2: number;
    radius: number;
    text: string;
    color: number;      // RGBA 32位
    lineWidth: number;
    style: 'solid' | 'dashed' | 'dotted';
}

function renderCommands(ctx: CanvasRenderingContext2D, commands: RenderCommand[]) {
    for (const cmd of commands) {
        // 颜色转换
        const color = intToRGBA(cmd.color);
        
        switch (cmd.type) {
            case 'line':
                ctx.beginPath();
                ctx.moveTo(cmd.x1, cmd.y1);
                ctx.lineTo(cmd.x2, cmd.y2);
                ctx.strokeStyle = color;
                ctx.lineWidth = cmd.lineWidth || 2;
                setLineStyle(ctx, cmd.style);
                ctx.stroke();
                break;
                
            case 'point':
                ctx.beginPath();
                ctx.arc(cmd.x1, cmd.y1, cmd.radius || 5, 0, 2 * Math.PI);
                ctx.fillStyle = color;
                ctx.fill();
                break;
                
            case 'circle':
                ctx.beginPath();
                ctx.arc(cmd.x1, cmd.y1, cmd.radius || 10, 0, 2 * Math.PI);
                ctx.strokeStyle = color;
                ctx.lineWidth = cmd.lineWidth || 2;
                ctx.stroke();
                break;
                
            case 'text':
                ctx.fillStyle = color;
                ctx.font = '14px monospace';
                ctx.fillText(cmd.text, cmd.x1, cmd.y1);
                break;
                
            case 'highlight':
                ctx.save();
                ctx.shadowColor = 'rgba(255,255,255,0.3)';
                ctx.shadowBlur = 20;
                ctx.beginPath();
                ctx.arc(cmd.x1, cmd.y1, cmd.radius || 15, 0, 2 * Math.PI);
                ctx.strokeStyle = color;
                ctx.lineWidth = 3;
                ctx.stroke();
                ctx.restore();
                break;
        }
    }
}

function intToRGBA(color: number): string {
    const a = (color >> 24) & 0xFF;
    const r = (color >> 16) & 0xFF;
    const g = (color >> 8) & 0xFF;
    const b = color & 0xFF;
    return `rgba(${r}, ${g}, ${b}, ${a/255})`;
}

function setLineStyle(ctx: CanvasRenderingContext2D, style: string) {
    if (style === 'dashed') {
        ctx.setLineDash([8, 6]);
    } else if (style === 'dotted') {
        ctx.setLineDash([3, 5]);
    } else {
        ctx.setLineDash([]);
    }
```

6.3 增量解析策略

为避免每次按键触发完整解析导致卡顿，采用防抖+增量解析策略：

```
用户输入
    ↓
防抖 300ms（用户暂停输入）
    ↓
获取当前文本全量
    ↓
调用 parseAll() 解析为命令序列
    ↓
与上次解析结果比较，计算差异
    ↓
仅将差异部分的命令发送给 L3 → L2
    ↓
L3 更新约束图 → 画布同步更新
```

```typescript
// text_parser.ts
class TextParser {
    private lastParsedCommands: Command[] = [];
    private debounceTimer: number | null = null;
    
    parseAndApply(text: string, controller: SceneController) {
        if (this.debounceTimer) {
            clearTimeout(this.debounceTimer);
        }
        this.debounceTimer = setTimeout(() => {
            const newCommands = this.parse(text);
            const diff = this.computeDiff(this.lastParsedCommands, newCommands);
            
            // 只发送差异部分
            for (const cmd of diff) {
                controller.executeCommand(cmd);
            }
            
            this.lastParsedCommands = newCommands;
            this.debounceTimer = null;
        }, 300);
    }
    
    computeDiff(oldCmds: Command[], newCmds: Command[]): Command[] {
        // 使用最小编辑距离算法，返回需要新增/删除的命令
        // 简化版：直接返回新命令列表（适用于小规模编辑）
        // 优化版：基于节点ID匹配，只发送变化的部分
        return newCmds;
    }
}
```

```tsx
            const { key, domEvent } = e;
            const charCode = domEvent.keyCode;
            
            if (domEvent.ctrlKey && charCode === 67) { // Ctrl+C
                terminal.current!.write('^C\r\n');
                commandBuffer.current = '';
                prompt();
                return;
            }
            
            if (domEvent.key === 'Enter') {
                const cmd = commandBuffer.current.trim();
                terminal.current!.write('\r\n');
                if (cmd) {
                    executeCommand(cmd);
                }
                commandBuffer.current = '';
                prompt();
                return;

                    terminal.current!.write('\r\n');
                    for (const c of completions) {
                        terminal.current!.writeln(`  ${c}`);
                    }
                    prompt();
                    terminal.current!.write(commandBuffer.current);
                }
                return;
            }
            
            if (domEvent.key === 'ArrowUp') {
                // 历史命令上翻（略）
                return;
            }
            
            if (key && key.length === 1 && key.charCodeAt(0) >= 32) {
                commandBuffer.current += key;
                terminal.current!.write(key);
            }
        });

            fitAddon.current?.fit();

        resizeObserver.observe(terminalRef.current);

            terminal.current?.dispose();
            resizeObserver.disconnect();
        };

        terminal.current?.write('\r\n> ');

            const result = controller.executeCommandString(cmd);
            if (result.success) {

            } else {
                terminal.current?.writeln(`✗ ${result.error_message || '执行失败'}`);
            }
        } catch (e: any) {
            terminal.current?.writeln(`✗ 异常: ${e.message}`);
        }
    };
    
    return <div ref={terminalRef} style={{ width: '100%', height: '100%' }} />;
```

```tsx
    }, [controller, setEdges]);
    
    return (

            <ReactFlow
                nodes={nodes}
                edges={edges}
                onNodesChange={onNodesChange}
                onEdgesChange={onEdgesChange}
                onNodeDragStop={onNodeDragStop}
                onConnect={onConnect}
                nodeTypes={nodeTypes}
                fitView
                snapToGrid
                snapGrid={[15, 15]}
            >
                <Background color="#333" gap={20} />
                <Controls />
                <MiniMap 
                    nodeColor="#4caf50" 
                    maskColor="rgba(0,0,0,0.3)"
                    style={{ background: '#1a1a1a' }}
                />
```

```typescript
            vscode.Uri.joinPath(this.context.extensionUri, 'webview', 'styles.css')
        );
        
        return `<!DOCTYPE html>
        <html>
        <head>
            <meta charset="UTF-8">
            <meta name="viewport" content="width=device-width, initial-scale=1.0">
            <link href="${styleUri}" rel="stylesheet">
            <title>Lv-00</title>
        </head>
        <body>

                // VSCode API 通信桥接

                // 全局配置
                window.LV00 = {
                    service: {
                        execute: (cmd) => vscode.postMessage({ command: 'executeCommand', payload: cmd }),
                        getState: () => vscode.postMessage({ command: 'getState' }),
                    }

            <script src="${scriptUri}"></script>

        const interval = setInterval(() => {

        this.panel.dispose();
        while (this.disposables.length) {

            if (d) d.dispose();
        }
    }
```

12.4 Native 服务桥接

```typescript
// Lv00Service.ts
import * as child_process from 'child_process';
import * as path from 'path';
import * as vscode from 'vscode';

// 使用 node-addon-api 加载的 L3 模块
// 或者通过 stdio 与独立进程通信
export class Lv00Service {
    private process: child_process.ChildProcess | null = null;
    private context: vscode.ExtensionContext;
    private callbacks: Map<string, (result: any) => void> = new Map();
    private requestId = 0;

    constructor(context: vscode.ExtensionContext) {
        this.context = context;
    }

    start() {
        const binPath = path.join(
            this.context.extensionPath,
            'bin',
            process.platform === 'win32' ? 'lv00-service.exe' : 'lv00-service'
        );
        
        this.process = child_process.spawn(binPath, ['--stdio'], {
            stdio: ['pipe', 'pipe', 'pipe'],
        });
        
        this.process.stdout?.on('data', (data) => {
            // 解析 JSON 响应
            try {
                const lines = data.toString().split('\n').filter((l: string) => l.trim());
                for (const line of lines) {
                    const msg = JSON.parse(line);
                    this.handleResponse(msg);
                }
            } catch (e) {
                console.error('解析服务响应失败:', e);
            }
        });
        
        this.process.stderr?.on('data', (data) => {
            console.error('Lv-00 服务错误:', data.toString());
        });
        
        this.process.on('exit', (code) => {
            console.log(`Lv-00 服务退出，代码: ${code}`);
            this.process = null;
        });
        
        console.log('Lv-00 服务已启动');
    }

    stop() {
        if (this.process) {
            this.process.kill();
            this.process = null;
        }
    }

    async execute(command: any): Promise<any> {
        return new Promise((resolve, reject) => {
            const id = ++this.requestId;
            this.callbacks.set(id.toString(), resolve);
            
            const msg = JSON.stringify({ id, ...command });
            this.process?.stdin?.write(msg + '\n');
            
            // 超时处理
            setTimeout(() => {
                if (this.callbacks.has(id.toString())) {
                    this.callbacks.delete(id.toString());
                    reject(new Error('请求超时'));
                }
            }, 5000);
        });
    }

    private handleResponse(msg: any) {
        if (msg.id && this.callbacks.has(msg.id.toString())) {
            const callback = this.callbacks.get(msg.id.toString());
            if (callback) {
                callback(msg.result);
                this.callbacks.delete(msg.id.toString());
            }
        }
    }
}
```

```typescript
    type: 'line' | 'point' | 'circle' | 'text' | 'highlight' | 'rect';
    x1: number;
    y1: number;
    x2?: number;
    y2?: number;
    radius?: number;
    text?: string;
    color: string;           // '#RRGGBB' 或 'rgba(...)'
```

14.3 性能优化策略

策略 说明
增量 Delta L1 只返回变更部分，不传输全量图
绘制指令批处理 L3 累积绘制指令，每帧批量发送
环形缓冲区 L2 维护 10000 条 Delta 记录，防止数据丢失
懒计算 各模态只在被激活时才计算投影数据
离屏渲染 Canvas 使用离屏缓冲，只绘制增量部分
防抖 文本编辑器在 300ms 无输入后才触发解析

十七、总结：六大核心实现细节

1. L1 API 封装：lv00_execute() + lv00_collect_delta() + lv00_normalize() 是 UI 端的三个基石函数，必须稳定。
2. L2 撤销栈：基于 L1 快照 lv00_snapshot() + lv00_restore() 实现，每个命令执行前自动打标。
3. L3 命中测试：世界坐标与屏幕坐标的双向转换 + 点到线段距离算法，是拖拽交互的物理基础。
4. L4 模态同步：所有模态共享同一个 SceneController 实例，通过 onStateChange 回调实现响应式更新。
5. 通信协议：使用 JSON-RPC over stdio（VSCode插件）或 WebSocket（独立应用），轻量且可调试。
6. 渲染管线：L3 生成 DrawCommand 列表 → L4 消费并渲染，每帧 60fps，增量更新。
