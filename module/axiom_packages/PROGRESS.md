### 4. classical_propositional_logic v1.0.0

### 5. ring_theory v1.0.0

**Mathematical Theory**: Ring theory — the study of rings, algebraic structures equipped with two binary operations (addition and multiplication). A ring (R, +, ·) is defined by 8 axioms: (R, +) is an abelian group, (R, ·) is a monoid, and multiplication distributes over addition. Ring theory bridges group theory and field theory, and is the algebraic foundation for number theory, algebraic geometry, and commutative algebra.
- **References**:

  - Wikipedia: Ideal (ring theory)
    https://en.wikipedia.org/wiki/Ideal_(ring_theory)
  - Wikipedia: Hilbert's tenth problem
    https://en.wikipedia.org/wiki/Hilbert%27s_tenth_problem
- **Primitive Notions**: ring element (member of carrier set R), addition + (abelian group operation), multiplication · (monoid operation, not necessarily commutative), additive identity 0, multiplicative identity 1
- **Core Axioms**: 8 axioms in 3 groups:
  - Group I. Additive Abelian Group (4): associativity of + (R1), commutativity of + (R2), additive identity (R3), additive inverse (R4)
  - Group II. Multiplicative Monoid (2): associativity of · (R5), multiplicative identity (R6)
  - Group III. Distributivity (2): left distributivity (R7), right distributivity (R8)
- **Constraint Templates**: 54 (5 additive group axioms + 3 multiplicative monoid axioms + 2 distributivity axioms + 12 elementary consequences + 6 core constructors + 9 derived element operations + 8 subring/ideal constructors + 8 more derived + 1 radical)

- **Contradiction Behavior**: explosion_principle
- **Relationship to group_theory**: A ring is an abelian group under addition. The additive structure of a ring is exactly the group theory axioms, so ring_theory naturally extends group_theory. The ring's multiplicative monoid structure is the additional algebraic layer.
- **Ring type hierarchy**: Commutative ring ⊃ Integral domain ⊃ GCD domain ⊃ UFD ⊃ PID ⊃ Euclidean domain ⊃ Field. Boolean rings (a·a = a) are rings where every element is idempotent; they correspond to Boolean algebras via Stone's representation theorem.

### 6. zfc_set_theory v1.0.0

**Mathematical Theory**: Zermelo-Fraenkel Set Theory with the Axiom of Choice (ZFC) — the standard axiomatic foundation for all of modern mathematics. All mathematical objects are encoded as pure, hereditarily well-founded sets in the von Neumann cumulative hierarchy V = ∪_{α∈Ord} V_α. ZFC is formalized in first-order logic with a single binary predicate ∈ (set membership).

- **References**:
  - Zermelo, E. (1908). "Untersuchungen über die Grundlagen der Mengenlehre I." Mathematische Annalen, 65: 261-281.
    https://doi.org/10.1007/BF01449999
  - Wikipedia: Zermelo-Fraenkel set theory
    https://en.wikipedia.org/wiki/Zermelo%E2%80%93Fraenkel_set_theory
  - Gödel, K. (1940). "The Consistency of the Continuum Hypothesis." Princeton University Press.
  - Cohen, P.J. (1963). "The Independence of the Continuum Hypothesis." PNAS, 50(6): 1143-1148.
    https://doi.org/10.1073/pnas.50.6.1143
  - Jech, T. (2003). "Set Theory: The Third Millennium Edition." Springer. ISBN 3-540-44085-2.
  - nLab: ZFC
    https://ncatlab.org/nlab/show/ZFC
  - Wikipedia: Continuum hypothesis
    https://en.wikipedia.org/wiki/Continuum_hypothesis
  - Wikipedia: List of statements independent of ZFC
    https://en.wikipedia.org/wiki/List_of_statements_independent_of_ZFC
- **Primitive Notions**: set membership (∈); all objects are pure sets (hereditarily well-founded); no urelements. Equality is defined by extensionality (same elements → same set).
- **Core Axioms**: 9 axioms:
  - Z1. Extensionality: ∀x∀y[∀z(z∈x ↔ z∈y) → x=y]
  - Z2. Regularity (Foundation): Every nonempty set has an ∈-minimal element.
  - Z3. Schema of Specification (Separation): Subsets defined by first-order formulas exist.
  - Z4. Pairing: {x,y} exists for any x,y.
  - Z5. Union: ∪x exists for any x.
  - Z6. Schema of Replacement: Images of sets under definable functions are sets.
  - Z7. Infinity: An inductive set (containing ∅ and closed under x↦x∪{x}) exists.
  - Z8. Power Set: P(x) exists for any x.
  - Z9. Choice (AC): For any family of nonempty disjoint sets, a choice set exists. **(Non-constructive oracle — proofs depending on AC carry light-orange solid port markings per design_v2.9.md §7.)**
- **Constraint Templates**: 29 (9 core ZFC axioms + 9 core set constructors + 12 derived set operations + 12 ordinal/cardinal constructors + 6 well-ordering/induction + 4 cumulative hierarchy + 4 AC equivalents)
- **Known Unconstructible/Konstruktionsprobleme**: 10 (continuum hypothesis/independent_of_ZFC, GCH/independent_of_ZFC, AC independence from ZF, inaccessible cardinal existence/equiconsistent, Suslin's hypothesis/independent_of_ZFC, Whitehead problem/independent_of_ZFC, ZFC consistency/unprovable_in_ZFC, measurable cardinal existence/transcends_ZFC, V=L/independent_of_ZFC, Martin's axiom/independent_of_ZFC)
- **Bottom Geometry**: zfc_cumulative_hierarchy — ⊥ is geometrically represented as the empty set ∅ at the foundation of the von Neumann cumulative hierarchy V = ∪_{α∈Ord} V_α
- **Negation Encoding**: classical_complement_in_set_universe — ¬φ encoded as complement within the set universe: {x∈V : ¬φ(x)} = V \ {x∈V : φ(x)}
- **Contradiction Behavior**: explosion_principle — ex contradictione quodlibet (from ⊥, any proposition P follows; carries light-orange dashed arrow marker)
- **Choice Oracle**: The `choice` template is a non-constructive oracle block (zero-input, outputs AC witness, light-orange solid port marker per planning_v3.0.md §Layer 2)
- **Relationship to existing packages**:
  - classical_propositional_logic: ZFC is formalized in first-order logic with equality; CPL provides the logical foundation (connectives, quantifier rules).
  - boolean_algebra: For any set X, its power set P(X) with ⊆, ∪, ∩, complement forms a Boolean algebra. ZFC provides the set-theoretic semantics for Boolean algebra structures.
  - group_theory: ZFC can encode group-theoretic structures as sets; a group is a set G equipped with a binary operation *: G×G→G satisfying the group axioms. All group theory can be developed within ZFC.
- **Key Independence Results**: ZFC has a uniquely rich landscape of independent statements — far more than any other axiom package so far. The independence of CH from ZFC (Gödel 1940, Cohen 1963) was a landmark result that launched modern set theory. The method of forcing (Cohen 1963) remains the primary tool for establishing independence from ZFC.

### 7. intuitionistic_propositional_logic v1.0.0

**Mathematical Theory**: Intuitionistic propositional logic (IPL), also known as constructive propositional logic. Formalized originally by Arend Heyting (1930) to provide a formal basis for L.E.J. Brouwer's programme of intuitionism. Unlike classical propositional logic (CPL), IPL rejects the law of excluded middle (φ ∨ ¬φ) and double negation elimination (¬¬φ → φ). The key constructive property is the disjunction property: if ⊢ φ ∨ ψ, then either ⊢ φ or ⊢ ψ.

- **References**:
  - Heyting, A. (1930). "Die formalen Regeln der intuitionistischen Logik I, II, III." Sitzungsberichte der Preußischen Akademie der Wissenschaften. pp. 42-56, 57-71, 158-169.
  - Wikipedia: Intuitionistic logic
    https://en.wikipedia.org/wiki/Intuitionistic_logic
  - nLab: Intuitionistic logic
    https://ncatlab.org/nlab/show/intuitionistic+logic
  - Stanford Encyclopedia of Philosophy: Intuitionistic Logic
    https://plato.stanford.edu/entries/logic-intuitionistic/
  - Troelstra, A.S. & van Dalen, D. (1988). "Constructivism in Mathematics: An Introduction" (2 vols). North-Holland.
  - Rybakov, V.V. (1997). "Admissibility of Logical Inference Rules." Studies in Logic, Vol. 136. Elsevier.
    https://en.wikipedia.org/wiki/Admissible_rule
  - Wikipedia: Heyting algebra
    https://en.wikipedia.org/wiki/Heyting_algebra
  - Statman, R. (1979). "Intuitionistic propositional logic is polynomial-space complete." TCS, 9(1): 67-72.
    https://doi.org/10.1016/0304-3975(79)90006-9
- **Primitive Notions**: propositional variable, ⊥ (falsum / absurdity); connectives → (implication), ∧ (conjunction), ∨ (disjunction), ⊥ — ALL primitive in IPL (unlike CPL where they are interdefinable). ¬φ is defined as φ → ⊥.
- **Core Axioms**: 9 Hilbert-style axiom schemas + 1 inference rule (Heyting, 1930):
  - THEN-1: φ → (ψ → φ) [K combinator / Weakening]
  - THEN-2: (φ → (ψ → χ)) → ((φ → ψ) → (φ → χ)) [S combinator / Distribution]
  - AND-1: φ ∧ ψ → φ, AND-2: φ ∧ ψ → ψ, AND-3: φ → (ψ → (φ ∧ ψ))
  - OR-1: φ → φ ∨ ψ, OR-2: ψ → φ ∨ ψ, OR-3: (φ → χ) → ((ψ → χ) → (φ ∨ ψ → χ))
  - FALSE (EFQ): ⊥ → φ
  - Rule: Modus Ponens (MP)
- **Constraint Templates**: 51 in 8 groups:
  - Group I (9): Core axiom schemata (K, S, AND-1/2/3, OR-1/2/3, FALSE)
  - Group II (1): Modus Ponens (sole inference rule)
  - Group III (5): Primitive connectives (→, ∧, ∨, ⊥, ¬)
  - Group IV (5): Derived connectives (↔, ⊕, NAND, NOR, ⊤)

### 28. linear_logic v1.0.0

**Mathematical Theory**: Linear logic — introduced by Jean-Yves Girard in 1987, a refinement of classical and intuitionistic logic that treats formulas as resources rather than truth values. The central insight is that logical connectives split into multiplicative and additive variants when structural rules (contraction and weakening) are restricted. Linear logic provides a fine-grained analysis of proof structure and has profound applications in computer science (linear type systems, concurrency, quantum computing, resource management).

- **References**:
  - Girard, J.-Y. (1987). "Linear Logic." *Theoretical Computer Science*, 50(1): 1-102. https://doi.org/10.1016/0304-3975(87)90045-4

- **Primitive Notions**: Linear proposition (formula treated as resource), linear sequent Γ ⊢ Δ (multisets of formulas), involutive negation ⊥ (De Morgan dualities with all connectives)
- **Core Connectives** (4 groups):

- **Sequent Calculus Rules** (Girard 1987):
  - Identity: init (B ⊢ B), cut (Γ₁ ⊢ B,Δ₁  Γ₂,B ⊢ Δ₂  ⇒  Γ₁,Γ₂ ⊢ Δ₁,Δ₂)

  - Additive: 0L, ⊤R, &L (i=1,2), &R, ⊕L, ⊕R (i=1,2)

  1. Provability in full propositional linear logic — undecidable (Lincoln, Mitchell, Scedrov, Shankar 1992)
  2. Provability in MELL — **open problem** (long-standing, marked as green_verified=false)

  - **classical_propositional_logic**: With exponentials, linear logic recovers classical logic: A ∨ B ≡ !(!(A ⊕ B)), A ∧ B ≡ !(A & B). The multiplicative excluded middle A ⅋ A⊥ is provable, while the additive A ⊕ A⊥ is not.

  - **category_theory**: MLL is modeled by *-autonomous categories. Linear logic provides a categorical semantics for proof theory and connects to monoidal categories.
  - **boolean_algebra**: The multiplicative conjunction ⊗ and additive conjunction & both generalize classical ∧, but with different resource semantics. Linear logic reveals the hidden resource structure in classical logic.
  - **proof_theory**: Linear logic was discovered through a semantic analysis of System F (polymorphic λ-calculus). Proof nets (Girard 1987) provide a graph-theoretic representation of proofs that eliminates bureaucracy.
- **Key Theorems & Properties**:
  - Cut elimination theorem (Girard 1987): Every proof in linear logic can be transformed into a cut-free proof.
  - Focused proof search (Andreoli 1992): Proofs can be organized into asynchronous (invertible) and synchronous (non-invertible) phases, improving proof search efficiency.
  - Phase semantics: A complete semantics for linear logic based on phase spaces (Girard 1987).
  - Curry-Howard correspondence: Linear logic proofs correspond to linear λ-calculus terms (linear types).
  - Resource interpretation: Formulas are resources that must be used exactly once (unless marked with ! or ?).
  - De Morgan dualities: (A ⊗ B)⊥ ≡ A⊥ ⅋ B⊥, (A & B)⊥ ≡ A⊥ ⊕ B⊥, (!A)⊥ ≡ ?(A⊥)

  - Additive excluded middle: ⊢ A ⊕ A⊥ is NOT provable (intuitionistic reading of disjunction)

### 48. cartesian_closed_category v1.0.0

**Mathematical Theory**: Cartesian closed category (CCC) — a category equipped with finite products and exponentials (internal hom-objects). CCCs are the categorical semantics of simply typed lambda calculus, and their internal logic is minimal logic (intuitionistic logic without ⊥). ### 49. topos_theory v1.0.0

**Mathematical Theory**: Elementary topos — a category that behaves like the category of sheaves of sets on a topological space. Topos theory unifies category theory, algebraic geometry, and mathematical logic. An elementary topos provides a "generalized mathematical universe" where one can do mathematics internally, with an intuitionistic higher-order logic. The internal language of a topos (Mitchell-Bénabou language) allows reasoning about topos objects as if they were sets.

### 37. affine_geometry v1.0.0

**Mathematical Theory**: Affine geometry — the study of geometric properties invariant under affine transformations. It is what remains of Euclidean geometry when the metric notions of distance and angle are "forgotten" (Euler 1748, Klein's Erlangen program 1872). The fundamental invariant is parallelism.
- **References**:
  - Coxeter, H.S.M. (1969). "Introduction to Geometry" (2nd ed.). Wiley.
  - Artin, E. (1957). "Geometric Algebra." Wiley. ISBN 978-1-118-16454-9.
  - Snapper, E. & Troyer, R.J. (1971). "Metric Affine Geometry." Springer-Verlag. ISBN 0-387-90036-5.
  - Berger, M. (1987). "Geometry, Vol. I & II." Springer. ISBN 3-540-11658-3.
  - Wikipedia: Affine geometry
    https://en.wikipedia.org/wiki/Affine_geometry
  - Wikipedia: Affine space
    https://en.wikipedia.org/wiki/Affine_space
  - nLab: Affine space
    https://ncatlab.org/nlab/show/affine+space
- **Primitive Notions**: point, line, vector (displacement); incidence, parallelism, subtraction (point - point = vector), translation (point + vector)
- **Core Axioms**: 17 axioms in 6 groups:
  - I. Incidence (4 axioms) — existence/uniqueness of points, lines, affine frames
  - II. Parallelism (4 axioms) — Playfair's axiom, parallelism as equivalence relation
  - III. Vector Space (11 axioms) — displacements form a vector space (abelian group + scalar multiplication)
  - IV. Affine Structure (4 axioms) — point-vector interaction (Chasles relation, translation-subtraction compatibility)
  - V. Desargues' Theorem (1 axiom) — free in dim >= 3, required in 2D
  - VI. Pappus's Theorem (1 axiom) — implies coordinate field commutativity
- **Constraint Templates**: 50 (4 incidence + 4 parallelism + 11 vector space + 4 affine structure + 7 affine combinations + 8 affine transformations + 2 theorems + 5 affine subspaces + 4 ratio/division + 4 parallelogram + 3 projective connection)
- **Known Unconstructible Problems**: 7 (perpendicular bisector, angle trisection, circle construction, finite affine plane non-prime-power existence, non-Desarguesian classification, metric recovery, area computation)
- **Bottom Geometry**: affine_space
- **Negation Encoding**: classical_material_implication
- **Contradiction Behavior**: explosion_principle

**File**: `axiom_packages/affine_geometry.lvz`
**Test**: `tests/test_axiom_affine_geometry.c` (10 test suites)

**Relationships to existing packages**:
- **euclidean_plane**: Affine geometry is Euclidean minus distance/angle; Euclidean is affine + metric structure
- **projective_geometry**: Affine = projective minus a line at infinity; projective completion adds points at infinity
- **hyperbolic_geometry**: The Klein model lives inside projective geometry; Beltrami-Klein model uses affine structure
- **elliptic_geometry**: Elliptic geometry has no parallel lines, unlike affine
- **field_theory**: Pappus's theorem implies the coordinate field is commutative
- **group_theory**: The translation group of an affine space is an abelian group

### 44. robin_arithmetic v1.0.0

**Mathematical Theory**: Robinson Arithmetic (Q) — the finitely axiomatized fragment of first-order Peano arithmetic, first set out by Raphael M. Robinson in 1950. Q is PA without the axiom schema of mathematical induction. It is the weakest theory strong enough for Gödel's first incompleteness theorem. Q is essentially undecidable: no consistent recursively axiomatized extension of Q is decidable (Tarski, Mostowski, Robinson 1953).

- **References**:
  - Robinson, R.M. (1950). "An Essentially Undecidable Axiom System." Proceedings of the ICM, pp. 729-730.
    https://en.wikipedia.org/wiki/Robinson_arithmetic
  - Wikipedia: Robinson arithmetic
    https://en.wikipedia.org/wiki/Robinson_arithmetic
  - nLab: Robinson arithmetic
    https://ncatlab.org/nlab/show/Robinson+arithmetic
  - Boolos, G.; Burgess, J.P.; Jeffrey, R. (2002). "Computability and Logic" (4th ed.). Cambridge University Press. Chapter 16.
  - Burgess, J.P. (2005). "Fixing Frege." Princeton University Press.
  - Mendelson, E. (2015). "Introduction to Mathematical Logic" (6th ed.). Chapman & Hall. pp. 202-203.
  - Tarski, A.; Mostowski, A.; Robinson, R.M. (1953). "Undecidable Theories." North Holland.
  - Bezboruah, A.; Shepherdson, J.C. (1976). "Gödel's Second Incompleteness Theorem for Q". JSL, 41(2): 503-512. https://doi.org/10.2307/2272251
  - Tourlakis, G. (2022). "Computability." Springer. Section 12.6.
  - Wikipedia: Essentially undecidable theory
    https://en.wikipedia.org/wiki/Essentially_undecidable_theory
  - Wikipedia: Tennenbaum's theorem
    https://en.wikipedia.org/wiki/Tennenbaum%27s_theorem
- **Primitive Notions**: natural number (element of domain N), zero constant 0, successor function S : N → N, addition + : N × N → N, multiplication · : N × N → N, identity/equality =
- **Core Axioms**: 7 axioms (Q1-Q7, Burgess 2005):
  - Q1: Sx ≠ 0 (zero is not a successor)
  - Q2: Sx = Sy → x = y (successor is injective)
  - Q3: y = 0 ∨ ∃x (Sx = y) (every number is zero or a successor — the only axiom with ∃)
  - Q4: x + 0 = x (addition base case)
  - Q5: x + Sy = S(x + y) (addition inductive case)
  - Q6: x · 0 = 0 (multiplication base case)
  - Q7: x · Sy = x · y + x (multiplication inductive case)
  - **No induction schema** — this is the defining difference from PA
- **Constraint Templates**: 39 in 5 groups:
  - Group I (7): Core Q axioms
  - Group II (4): Definitional extension — order relation (less-than, zero-impossible, successor relation, trichotomy)
  - Group III (12): Elementary consequences provable in Q (zero predecessor property, successor-not-self-instance, add/mul zero left, add/mul one right/left, associativity/commutativity/distributivity instances, less-than irreflexive/transitive instances, zero is least successor)
  - Group IV (8): Core constructors (successor, predecessor, add, multiply, zero, numeral, less-than check, equality check)
  - Group V (8): Derived constructors (truncated subtraction, exponentiation, parity check, max/min, truncated division, remainder, GCD)
- **Known Unconstructible Problems**: 12:
  1. Consistency of Q — Gödel's second incompleteness {7 deps}
  2. Gödel sentence for Q — Gödel's first incompleteness {3 deps}
  3. Addition commutativity (general) — requires induction {3 deps}
  4. Multiplication commutativity (general) — requires induction {4 deps}
  5. Addition associativity (general) — requires induction {3 deps}
  6. Sx ≠ x (general) — requires induction {3 deps}
  7. Decidability of Q — essentially undecidable {7 deps}
  8. Decidability of any consistent extension of Q — Tarski-Mostowski-Robinson theorem {7 deps}
  9. Hilbert's tenth problem for Q — MDRP theorem / Diophantine unsolvability {3 deps}
  10. Nonstandard model characterization of Q — Tennenbaum's theorem does not apply {3 deps}
  11. Uniform solvability of equations in Q — Diophantine set unsolvability {2 deps}
  12. Recursive separability of Q theorems from refutations — essential inseparability {7 deps}
- **Bottom Geometry**: natural_number_zero_without_predecessor — ⊥ is geometrically represented as the zero element without a predecessor. The structure is infinite but has a well-defined foundation at 0. Unlike PA, Q lacks the inductive "climbing" structure — the standard part is embedded but non-standard models can have "rogue" elements.
- **Negation Encoding**: classical_falsum_in_first_order_logic — Q uses classical first-order logic with identity as its background logic. Negation is classical: ¬φ means φ is false (φ → ⊥). The falsum ⊥ is the contradiction that any false statement entails.
- **Contradiction Behavior**: explosion_principle — Q is a classical theory. From ⊥ (contradiction), any proposition follows via ex falso quodlibet.
- **Relationship to existing packages**:
  - **peano_arithmetic**: Q is a proper sub-theory of PA. PA adds the induction schema to Q. Every theorem of Q is a theorem of PA, but the converse is not true (commutativity of addition is a PA theorem but not a Q theorem). Q was explicitly designed by Robinson as the minimal set of PA axioms needed to prove that all computable functions are representable.
  - **zfc_set_theory**: Q is interpretable in a very weak fragment of ZFC (General Set Theory: extensionality + empty set + adjunction). This is the weakest set theory that can interpret arithmetic.
  - **computability_theory**: Q is the canonical example of an essentially undecidable theory. All computable functions are representable in Q. The essential undecidability of Q is the key step in proving the undecidability of first-order logic and the Entscheidungsproblem.
  - **number_theory**: Q captures the most basic number-theoretic operations. All elementary number theory can be encoded in Q, though generalizations typically require induction (not available in Q).
  - **classical_propositional_logic**: Q uses first-order logic with identity as its background logic. All propositional tautologies are derivable in Q.
  - **model_theory**: Q has nonstandard models and is a classic example of the compactness theorem. Unlike PA, Q has computable nonstandard models (Tennenbaum's theorem does not apply).
  - **proof_theory**: Gentzen's consistency proof for PA uses transfinite induction up to ε₀. Q, being weaker, does not require such strong methods — but still Gödel's second incompleteness holds for Q.
  - **Presburger arithmetic**: Q contains Presburger arithmetic's language but is not a sub-theory (Q has multiplication; Presburger is addition-only and is decidable).
- **Key Properties of Q**:
  - **Finitely axiomatizable**: Only 7 axioms, no axiom schemas (unlike PA's infinite induction schema)
  - **Essentially undecidable**: Even adding any finite or recursively enumerable set of true arithmetic sentences to Q yields an undecidable theory
  - **Recursively incompletable**: There is no consistent, complete, recursively axiomatizable extension of Q
  - **Computable nonstandard models**: The simplest has a single nonstandard "rogue" element ∞ with S(∞)=∞, plus all standard numbers
  - **Representability of computable functions**: This is the key property that makes Gödel's first incompleteness theorem work for Q
  - **Gödel's second incompleteness holds for Q** (Bezboruah & Shepherdson 1976) — no consistent recursively axiomatizable extension of Q can prove its own consistency
  - **If any single axiom is dropped, the theory is no longer essentially undecidable**
  - **Instance-regimented**: Specific instances are provable (e.g., 5+7=7+5), but general statements are not (e.g., ∀x∀y(x+y=y+x))
  - **The sum of cubes 1³+2³+...+n³ is NOT definable in Q** — this is a consequence of lacking induction

### 42. presburger_arithmetic v1.0.0

**Mathematical Theory**: Presburger Arithmetic — the first-order theory of natural numbers with addition only, introduced by Mojżesz Presburger in 1929. Unlike Peano Arithmetic (which includes multiplication), Presburger arithmetic is consistent, complete, and decidable, but not finitely axiomatizable. It is one of the rare examples of a complete, decidable first-order theory that is rich enough to be mathematically interesting.

- **References**:

    https://doi.org/10.1137/0203024
  - Cooper, D.C. (1972). "Theorem Proving in Arithmetic without Multiplication." Machine Intelligence 7, pp. 91-99.
  - Büchi, J.R. (1962). "On a Decision Method in Restricted Second Order Arithmetic." Stanford University Press, pp. 1-11.
  - Oppen, D.C. (1978). "A 2^2^2^pn Upper Bound on the Complexity of Presburger Arithmetic." J. Comput. Syst. Sci., 16(3): 323-332.
  - Nipkow, T. (2010). "Linear Quantifier Elimination." J. Autom. Reasoning, 45(2): 189-212.
  - Enderton, H.B. (2001). "A Mathematical Introduction to Logic" (2nd ed.). Academic Press.

    https://plato.stanford.edu/entries/arithmetic/
  - nLab: Presburger arithmetic
    https://ncatlab.org/nlab/show/Presburger+arithmetic
- **Primitive Notions**: constant 0 (zero), constant 1 (one), binary operation + (addition), equality =
- **Core Axioms**: 5 (P1: zero not successor, P2: successor injectivity, P3: additive identity, P4: recursive addition, P5: induction schema)
- **Constraint Templates**: 74 (5 core axioms + 12 elementary consequences + 6 order relation + 6 constant multiplication + 8 parity/divisibility + 6 linear Diophantine + 4 quantifier elimination + 4 automata-theoretic + 5 model theory + 6 core constructors + 8 derived constructors + 4 formal verification applications)
- **Known Unconstructible Problems**: 10 (primality/inexpressible, general multiplication/inexpressible, general divisibility/inexpressible, exponentiation/inexpressible, Goldbach conjecture/inexpressible, Fermat's last theorem/inexpressible, Goodstein theorem/inexpressible, Gödel sentence/inexpressible, satisfiability/2-EXPTIME-complete, bit-vector arithmetic/undecidable extension)
  - Note: Presburger arithmetic is DECIDABLE, so "inexpressible" means the concept cannot be formulated in the language (requires multiplication between variables). "2-EXPTIME-complete" is a complexity barrier, not logical undecidability.
