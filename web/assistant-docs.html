Lv-00 编程助手使用文档

符号几何元语言引擎 -- 编程辅助接口完整参考手册

1. 系统概述

Lv-00 是一个符号几何元语言引擎，提供精确的几何构造、约束求解、形式化证明和编程辅助能力。编程助手模块（AI Assistant）作为核心交互接口，支持以下功能域：

  • WebAssembly 绑定层开发 -- C 核心到浏览器的桥接
  • Canvas 2D 几何渲染器 -- 可视化几何图形
  • 核心 API 查询与交叉引用 -- 快速查找函数签名
  • 形式化概念解析 -- 符号坐标、约束图、归一化、合一检查
  • 代码审查与质量分析 -- 多 Agent 模式（编程/审查/解释）
  • 数学计算与公式编辑 -- DSL / LaTeX / Python 三种语法模式
编程助手采用 SSE（Server-Sent Events）流式输出，支持实时查看生成过程。

2. 安装与启动

2.1 环境要求

依赖项最低版本说明
Node.jsv18+用于构建工具链
Emscriptenv3.1+C 到 WebAssembly 编译器
现代浏览器Chrome 90+ / Firefox 90+支持 WASM 和 ES2020

2.2 构建步骤

# 克隆项目
git clone https://github.com/example/lv00.git
cd lv00

# 编译 C 核心到 WebAssembly
emcc src/lv00_core.c \
     -o web/lv00.wasm \
     -s EXPORTED_FUNCTIONS="[...]" \
     -s EXPORTED_RUNTIME_METHODS="[...]" \
     -O2

# 启动本地开发服务器
python -m http.server 8080 -d web

2.3 启动

在浏览器中打开 http://localhost:8080，点击顶部标签栏的 [AI] 标签即可进入编程助手面板。

必须通过 HTTP 服务器访问，直接打开 HTML 文件（file:// 协议）将无法加载 WebAssembly 模块。

4. 公式编辑器

Lv-00 的公式编辑器支持三种输入语法，可覆盖从简单数学表达式到复杂几何定理的各类场景。

4.1 DSL 语法（领域特定语言）

DSL 是 Lv-00 的原生公式语法，专为几何构造设计，语法简洁且与核心引擎直接对应。

基本表达式

// 定义点
let A = point(0, 0)
let B = point(3, 4)

// 定义线段
let seg = segment(A, B)

// 计算距离
let d = distance(A, B)  // => 5

// 添加约束
constrain(A, B, incidence)
constrain(A, B, C, betweenness)

复合构造

// 中点
let M = midpoint(A, B)

// 垂直平分线
let perp = perpendicular_bisector(A, B)

// 圆（圆心 + 半径）
let c = circle(O, r)

4.2 LaTeX 语法

支持标准 LaTeX 数学模式，适用于论文写作和文档生成场景。

// 行内公式
$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$

// 独立公式块
$$
\angle ABC = \arccos\left(\frac{\vec{BA} \cdot \vec{BC}}{|\vec{BA}||\vec{BC}|}\right)
$$

// 几何定理
$\triangle ABC \cong \triangle DEF \iff AB=DE \land AC=DF \land \angle BAC = \angle EDF$
LaTeX 公式会在渲染时自动转换为可视化数学符号显示。

4.3 Python 语法

Python 语法模式适用于数值计算和脚本化操作，与标准 Python 数学库兼容。

import math

# 基本计算
distance = math.sqrt((3 - 0)**2 + (4 - 0)**2)
print(f"距离: {distance}")  # 距离: 5.0

# 向量运算
def dot_product(v1, v2):
    return sum(a * b for a, b in zip(v1, v2))

# 角度计算
angle = math.acos(
    dot_product(ba, bc) /
    (math.sqrt(dot_product(ba, ba)) * math.sqrt(dot_product(bc, bc)))
)

6. 函数块系统

函数块（Function Block）是 Lv-00 的核心封装机制，允许将几何构造序列打包为可复用的模块。

6.1 打包函数块

// 定义一个函数块：等边三角形构造
block equilateral_triangle(A, B) {
    let C = construct_third_vertex(A, B, 60);
    let s1 = segment(A, B);
    let s2 = segment(B, C);
    let s3 = segment(C, A);
    return { C, s1, s2, s3 };
}

6.2 实例化

// 实例化函数块
let result = equilateral_triangle(P1, P2);
// result.C  => 第三个顶点
// result.s1, s2, s3 => 三条边

6.3 组合

// 函数块组合：六边形 = 6 个等边三角形
block hexagon(center, radius) {
    let vertices = [];
    for (let i = 0; i < 6; i++) {
        vertices.push(rotate_point(center, start, i * 60));
    }
    // 连接所有顶点
    return polygon(vertices);
}
函数块支持参数化输入，实例化时自动进行类型检查和约束传播。

7. 类型系统

Lv-00 的类型系统为几何对象提供形式化类型标注，支持类型创建、等价检查和层级检查。

7.1 类型创建

// 基础类型
type Point       = { x: Symbol, y: Symbol }
type Segment     = { from: Point, to: Point }
type Triangle    = { a: Point, b: Point, c: Point }
type Circle      = { center: Point, radius: Symbol }

// 复合类型
type RightTriangle = Triangle with { right_angle_at: Vertex }

7.2 等价检查

// 检查两个类型是否等价
let eq = lv00_type_equivalent(Segment, Line);  // false
let eq2 = lv00_type_equivalent(Triangle, Triangle);  // true

// 结构等价检查
let struct_eq = lv00_type_structural_eq(t1, t2);

7.3 层级检查

// 子类型关系检查
let is_sub = lv00_type_is_subtype(RightTriangle, Triangle);  // true
let is_sub2 = lv00_type_is_subtype(Point, Triangle);  // false

// 类型层级查询
let parents = lv00_type_supertypes(IsoscelesTriangle);
// => [Triangle, Polygon, GeometricObject]

8. 证明系统

Lv-00 的证明系统支持几何命题的形式化验证，基于构造性证明和合一检查（Unification）。

8.1 命题创建

// 声明一个待证命题
proposition "三角形内角和为180度" {
    given:
        ABC is Triangle
    prove:
        angle(A) + angle(B) + angle(C) = 180
}

8.2 合一检查

// 检查两个表达式是否可合一
let result = lv00_unify(
    "distance(A, B)",
    "distance(X, Y)"
);
// => { A: X, B: Y }  (替换映射)

// 合一失败的情况
let fail = lv00_unify(
    "segment(A, B)",
    "triangle(A, B, C)"
);
// => null  (不可合一)

8.3 证明导航

切换到 Proof 面板可查看证明树的结构：

  • 证明树视图 -- 显示命题的完整推导过程
  • 步骤导航 -- 逐步前进/后退查看证明细节
  • 依赖追踪 -- 高亮显示当前步骤依赖的公理和引理
  • 间隙检测 -- 自动标记证明中未完成的步骤
点击证明树中的任意节点可展开查看该步骤的详细推导。

9. 递归系统

递归系统确保递归定义的函数和构造过程能够正确终止，基于测度函数（Measure Function）进行终止性检查。

9.1 测度创建

// 为递归函数定义测度
measure depth(tree) {
    return tree_height(tree);
}

// 递归函数声明
recursive traverse(tree) decreases depth(tree) {
    if (is_leaf(tree)) return [];
    return [
        tree_value(tree),
        ...traverse(left_child(tree)),
        ...traverse(right_child(tree))
    ];
}

9.2 终止检查

// 系统自动验证终止性
let check = lv00_check_termination("traverse");
// => { terminates: true, measure: "depth", proof: "..." }

// 终止检查失败示例
let bad = lv00_check_termination("infinite_loop");
// => { terminates: false, error: "测度未严格递减" }

9.3 几何递归示例

// Koch 雪花曲线的递归构造
recursive koch_segment(A, B, depth)
    decreases depth
{
    if (depth == 0) return [segment(A, B)];

    let P1 = third_point(A, B, 1/3);
    let P2 = third_point(A, B, 2/3);
    let Peak = equilateral_peak(P1, P2);

    return [
        ...koch_segment(A, P1, depth - 1),
        ...koch_segment(P1, Peak, depth - 1),
        ...koch_segment(Peak, P2, depth - 1),
        ...koch_segment(P2, B, depth - 1)
    ];
}

11. 常见问题 (FAQ)

Q1: WebAssembly 模块加载失败怎么办？

确保通过 HTTP 服务器访问页面（而非 file:// 协议），并检查 .wasm 文件与 HTML 文件在同一目录下。如果使用自定义 MIME 类型，确保服务器正确设置 application/wasm。

Q2: 图归一化（normalize）是幂等的吗？

是的。graph_normalize 满足幂等性：normalize(normalize(G)) == normalize(G)。归一化过程合并语义等价的顶点和边，重复调用不会产生额外变更。

Q3: 符号坐标和数值坐标有什么区别？

数值坐标使用浮点数表示位置，存在精度丢失问题。符号坐标使用代数符号（如 x, y）表示位置，通过符号计算保持精确性。Lv-00 默认使用符号坐标，仅在渲染时转换为数值。

Q4: 如何调试证明失败的问题？

在 Proof 面板中，失败的步骤会以红色高亮显示。点击该步骤可查看：

  1. 当前目标（Goal）
  2. 已应用的规则（Rule）
  3. 失败原因（如：合一失败、前提不满足）

Q5: 函数块实例化时类型不匹配怎么办？

检查函数块定义的参数类型与传入参数的类型是否兼容。使用 lv00_type_is_subtype 确认子类型关系。如果需要泛型支持，可在函数块定义中使用类型变量。

Q6: 递归终止检查失败如何修复？

常见原因及解决方案：

  • 测度未定义 -- 为递归函数添加 decreases 子句
  • 测度未严格递减 -- 确保每次递归调用时测度值严格减小
  • 缺少基础情况 -- 添加递归的基础终止条件

Q7: 编程助手支持哪些 LLM 后端？

编程助手通过统一 LLM 调用层支持多种后端，包括 OpenAI API、本地模型（通过 Ollama）和自定义端点。在配置面板中设置 API 密钥和端点地址即可切换。

Q8: 如何扩展自定义约束类型？

// 在 C 核心中注册自定义约束
LV00_CONSTRAINT_TYPE my_constraint = lv00_register_constraint(
    "my_custom",
    check_fn,      // 验证函数
    serialize_fn,  // 序列化函数
    deserialize_fn  // 反序列化函数
);
