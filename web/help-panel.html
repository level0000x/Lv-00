快速开始 Quick Start

[Overview] Lv-00 系统简介

Lv-00 是一个符号几何元语言引擎，用于：

  • 精确的几何构造（使用符号坐标而非浮点数）
  • 约束求解和图归一化
  • 几何证明和验证
  • 函数块封装和组合

[Quick Start] 快速上手

  1. 创建点
    点击工具栏的 "Point" 按钮，在画布上点击创建点
  2. 创建线段
    选择 "Segment" 工具，点击两个点创建线段
  3. 添加约束
    右键点击点，选择 "Incidence" 或 "Betweenness"
  4. 归一化
    点击 "Normalize" 按钮合并重复元素
  5. 查看证明
    切换到 Proof 面板查看构造过程

核心概念 Core Concepts

[Concept] 符号坐标系统

Lv-00 使用符号坐标而非浮点数，支持：

  • 有理数 - 精确分数表示 (1/2, 3/4)
  • 代数数 - 多项式根 (sqrt(2), cbrt(5))
  • 二次根式 - a + b*sqrt(n) 形式
  • 超越常数 - pi, e

[Note] 符号坐标保证了几何构造的精确性，避免了浮点误差。

[Concept] 约束图

约束图是 Lv-00 的核心数据结构：

  • 节点 - 点、线段、区域、端口、函数块
  • 约束 - 关联、之间、相交、包含、连接

[Note] 约束图描述了几何对象之间的关系，求解器根据约束计算坐标。

[Concept] 归一化 (Normalization)

归一化是 Lv-00 保证幂等性的核心机制：

  1. 合并坐标相同的点
  2. 合并端点相同的线段
  3. 稳定化拓扑排序

[Note] 归一化后的图再次归一化不会产生变化。

[Concept] 合一检查 (Unification)

合一检查是证明系统的核心：

  1. 归一化构造图和命题图
  2. 展开命题中的模板
  3. 三层匹配：端口 - 约束 - 坐标

[Note] 合一成功意味着命题得证。

[Concept] 信任颜色系统

Lv-00 使用颜色编码构造的可靠性：

[GREEN] 全构造，无非常规依赖
[BLUE] 待完成（未探索/资源受限）
[YELLOW] 条件性不可构造
[ORANGE] 非构造性依赖
[RED] 错误/冲突
编程指南 Coding Guide

[Dev] WebAssembly 绑定

为 C 函数创建 JavaScript 可调用的绑定：

// C 代码
EMSCRIPTEN_KEEPALIVE
int web_graph_add_point(void* graph, double x, double y) {
    if (!graph) return -1;

    ConstraintGraph* g = (ConstraintGraph*)graph;
    SymbolicCoord* coords[2];
    coords[0] = symbolic_coord_create_rational(x, 1);
    coords[1] = symbolic_coord_create_rational(y, 1);

    AddNodeResult result = graph_add_point(g, coords, 2);
    symbolic_coord_destroy(coords[0]);
    symbolic_coord_destroy(coords[1]);

    return (result == ADD_NODE_OK) ? g->next_node_id - 1 : -1;
}
// JavaScript 调用
const pointId = Module.ccall(
    'web_graph_add_point',
    'number',           // 返回类型
    ['number', 'number', 'number'],  // 参数类型
    [graphPtr, 1.0, 2.0]            // 参数值
);

[Dev] Canvas 渲染

坐标系转换是渲染的关键：

// 世界坐标 - 屏幕坐标
worldToScreen(wx, wy) {
    return {
        x: (wx * this.zoom) + this.offset.x,
        y: (wy * this.zoom) + this.offset.y
    };
}

// 屏幕坐标 - 世界坐标
screenToWorld(sx, sy) {
    return {
        x: (sx - this.offset.x) / this.zoom,
        y: (sy - this.offset.y) / this.zoom
    };
}

常见问题 FAQ

[Q] 如何保存和加载构造？

使用 "Export" 按钮导出为 JSON 格式，使用 "Import" 按钮加载。证明可以导出为 HTML、LaTeX 或 Coq 脚本。

[Q] 为什么我的点消失了？

可能是归一化时与其他点合并了。检查是否有坐标相同的点，或使用不同的坐标值。

[Q] 如何创建函数块？

1. 在 Graph 面板选择要封装的元素
2. 切换到 Block 面板
3. 点击 "Pack" 按钮
4. 指定输入/输出端口

[Q] 证明失败怎么办？

检查：
- 构造图是否完整
- 命题模式是否匹配
- 约束是否正确添加
- 是否已执行归一化

[Q] 如何调试 WebAssembly？

1. 打开浏览器开发者工具 (F12)
2. 查看 Console 中的日志
3. 使用 Debug 面板查看内部状态
4. 在 C 代码中添加 printf 输出

[Q] WASM 模块加载失败怎么办？

常见原因及解决方案：
- 确保通过 HTTP 服务器访问（不支持 file:// 协议）
- 检查 .wasm 文件与 HTML 在同一目录下
- 确认服务器正确设置了 application/wasm MIME 类型
- 检查浏览器控制台是否有 CORS 跨域错误
- 尝试清除浏览器缓存后重新加载

[Q] Canvas 渲染出现空白或闪烁怎么办？

排查步骤：
- 按 F12 打开开发者工具，检查 Console 是否有 WebGL/Canvas 错误
- 确认显卡驱动已更新到最新版本
- 尝试在浏览器设置中启用硬件加速
- 检查画布容器尺寸是否为 0（可能被 CSS 隐藏）
- 如果使用高 DPI 屏幕，确认 devicePixelRatio 缩放正确

[Q] 模块标签切换后内容不显示？

可能原因及解决方法：
- 检查对应面板的 HTML 是否已成功加载（查看网络请求）
- 确认面板容器没有被 CSS display:none 以外的规则隐藏
- 尝试点击其他标签再切回，触发重新渲染
- 如果使用 integrate-all.js，确认扩展面板的加载顺序正确
- 刷新页面后重试
