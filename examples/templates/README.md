# LV-00 模板库

本目录包含 LV-00 几何系统的常用构造模板。

## 模板列表

### 1. template_triangle.lv00
通用三角形构造模板
- 支持等边、等腰、直角、不等边三角形
- 可配置显示高、中线、角平分线
- 支持外接圆和内切圆显示

### 2. template_polygon.lv00
正多边形构造模板
- 可配置边数、半径、起始角度
- 支持对角线、外接圆、内切圆显示
- 自动计算周长和面积

### 3. template_circle.lv00
圆的几何构造模板
- 支持基本圆、内接多边形、外切多边形
- 支持切线构造
- 可配置显示半径、直径、弦

### 4. template_construction.lv00
尺规作图模板
- 垂线构造
- 平行线构造
- 角平分线构造
- 垂直平分线构造
- 复制线段和角

### 5. template_proof.lv00
几何证明模板
- 全等三角形证明
- 相似三角形证明
- 平行/垂直证明
- 线段/角度相等证明
- 共线/共圆证明

## 使用方法

1. 复制模板文件
2. 修改 `config` 部分的参数
3. 运行 LV-00 系统加载模板

## 示例

```lv00
// 使用三角形模板构造等边三角形
config {
    type: "equilateral",
    A: { x: 0, y: 0 },
    B: { x: 6, y: 0 },
    show_medians: true,
    show_circumcircle: true
}
```
