# LV-00 案例库

本目录包含 LV-00 几何系统的基础几何案例，共10个案例，涵盖三角形、圆、多边形等基础几何图形。

## 案例列表

### 三角形案例

#### 1. triangle_equilateral.lv00 - 等边三角形
- 构造等边三角形
- 证明三边相等
- 证明三角相等（均为60°）

#### 2. triangle_right.lv00 - 直角三角形
- 构造直角三角形
- 证明勾股定理
- 计算面积

### 圆案例

#### 3. circle_basic.lv00 - 圆的基本性质
- 圆的定义和构造
- 切线构造
- 直径所对圆周角为直角

### 多边形案例

#### 4. polygon_square.lv00 - 正方形
- 正方形构造
- 对角线性质（相等且垂直平分）
- 面积和周长计算

#### 5. polygon_regular_pentagon.lv00 - 正五边形
- 正五边形构造
- 黄金比例展示
- 对角线与边长关系

### 几何关系案例

#### 6. geometry_parallel_lines.lv00 - 平行线
- 平行线构造
- 同位角、内错角相等证明
- 平行四边形性质

#### 7. geometry_perpendicular.lv00 - 垂线
- 垂线构造
- 垂直平分线性质
- 直角三角形构造

#### 8. geometry_similar_triangles.lv00 - 相似三角形
- 相似三角形构造
- 相似比和面积比
- 中位线定理

#### 9. geometry_concyclic.lv00 - 四点共圆
- 四点共圆判定
- 对角互补证明
- 托勒密定理

#### 10. geometry_angle_bisector.lv00 - 角平分线
- 角平分线构造
- 角平分线定理
- 内心和内切圆

#### 11. geometry_midpoint_connector.lv00 - 中位线定理
- 三角形中位线构造
- 中位线定理证明
- 重心性质

## 使用方法

1. 在 LV-00 系统中加载案例文件
2. 查看几何构造和证明过程
3. 修改参数进行自定义探索

## 学习路径

1. **入门**：从 triangle_equilateral.lv00 开始，了解基本语法
2. **进阶**：学习 circle_basic.lv00 和 polygon_square.lv00
3. **提高**：研究相似三角形和共圆案例
4. **精通**：掌握角平分线和中位线定理
