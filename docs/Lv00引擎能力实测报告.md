# Lv-00 引擎能力实测报告（.lv 语言桥接层）

> 日期：2026-08-14
> 方法：编译探针程序直接链接 `Lv-00/build3/liblv.a`，调用 `lv_load_file` / `lv_apply_parse_result` / `lv_verify_proofs` / graph API 实测
> 范围：.lv 语言 → Lv-00 引擎的桥接层（lv_loader.c）能力边界

---

## 一、已验证可用（真实工作）

| 能力 | 证据 |
|:---|:---|
| .lv 文件解析（lex→parse→sema） | 全部 18 个迁移文件 error_count=0 |
| Point 声明注册到引擎 | `graph_get_node_count` 正确返回节点数（如 gaze.lv 45 节点） |
| 记录类型声明 `Point X := {...}` | 语法接受并应用成功 |
| 几何表达式 `Point X := point(0,0)` | 语法接受并应用成功 |
| 算术/布尔/λ Prove 机械验证 | `Prove add(2,3)==5` PASS、`Prove 2+2==5` FAIL（test_lv_bootstrap 实测） |
| 命题逻辑真值表验证 | 排中律等恒真定律 PASS、反例 FAIL |
| 引擎核心（图、求解、证明、Groebner） | build3 150+ 测试 exe 全 PASS |

## 二、桥接层未实现（解析通过但语义丢失）

| 语法 | 现状 | 影响 |
|:---|:---|:---|
| `Point A := {x:0, y:0}` / `point(0,0)` | 语法接受，但 loader 用默认坐标 (0,0) 注册，**坐标值被丢弃** | ROSE 设计的空间布局语义无法表达 |
| `Constraint X: dist(a,b) = N;` | 解析通过，**未写入引擎约束图**（约束数=0） | 距离约束（=0 表示闭环/合并）语义丢失 |
| `Constraint X: perpendicular(...)` 等 | 解析通过，未处理 | 几何谓词约束无法表达 |
| `Constraint X: collinear(a,b,c)` | 有处理代码，但要求参数为真实 ID 且降级为点-线 incidence，**多数场景实际跳过** | 共线约束无法可靠表达 |
| `Line L = line(a,b)` 构造 | Line 声明走 `decl_stash`，**仅暂存名称未创建实体** | 线段/直线无法创建 |
| `Prove;`（无参） | 仅标记意图，无验证语义 | — |

## 三、对 ROSE-SCA 的意义

ROSE-SCA 的设计（19 个 .lv00 → 18 个 .lv 已迁移）**全部能被新引擎解析并注册节点**，
但桥接层（loader）目前只实现了最小子集：

1. **节点层可用**：所有 Point 声明会真实进入引擎约束图
2. **约束层未接**：distance/collinear/perpendicular 等约束语义尚未写入引擎
3. **坐标层未接**：声明中的坐标值被忽略（引擎 API `lv_add_point` 支持精确坐标，但 loader 未使用声明值）

这意味着：**ROSE-SCA 设计的"几何约束图"表达要真正跑起来，需要补全 loader 的约束处理**——
这是 Lv-00 桥接层的主要未完成工作（与项目"大部分功能未写"的现状一致）。

## 四、迁移工具的应对

`sighted-wiki/tools/lv00_to_lv.py` 已针对上述缺口做语义保留：

- 坐标/构造值 → `// [lv00] 原值: ...` 注释（等 loader 支持后可直接恢复）
- distance=0 → `// [lv00] 距离 0: 表示闭环/合并/同节点语义` 标注
- collinear → 标注"引擎 loader 唯一已实现的谓词"

全部 18 个迁移文件可解析、可应用、可回滚，设计语义以注释形式完整保留。

---

## 五、建议的后续工作（按优先级）

1. **补全 loader 约束处理**（`lv_loader.c` 第三遍）：dist 约束 → `graph_add_constraint`；坐标声明值 → `lv_add_point` 真实坐标
2. **Line 声明支持**：`decl_stash` → 根据构造值创建线段实体
3. **Prove 语义绑定**：无参 Prove 映射到当前文件的全部约束可满足性检查
4. **迁移工具增强**：loader 补全后移除 [lv00] 注释，恢复坐标/约束为活跃代码
