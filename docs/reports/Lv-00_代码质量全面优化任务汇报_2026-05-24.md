## 三、已修复问题详情

### 3.1 高危问题修复（31个）

#### 3.1.1 安全风险修复

**问题 1: 硬编码开发密钥**
- **文件**: `concurrent_monitor/web/routes.py`
- **严重性**: 高危
- **描述**: 存在硬编码的开发密钥，存在安全风险
- **修复方案**: 移除硬编码密钥，强制要求环境变量配置
- **修复代码**:
```python
# 修复前
_DEV_SECRET_KEY = "dev-secret-key-do-not-use-in-production-2024"
secret_key = os.environ.get("MONITOR_SECRET_KEY") or _DEV_SECRET_KEY

# 修复后
secret_key = os.environ.get("MONITOR_SECRET_KEY")
if not secret_key:
    raise RuntimeError(
        "MONITOR_SECRET_KEY 环境变量未设置，请配置后重新启动。"
    )
```

**问题 2: 全局 API Key 竞争**
- **文件**: `llm_coding_assistant/core/ai_engine.py`
- **严重性**: 高危
- **描述**: dashscope API key 使用全局配置，多实例场景下不安全
- **修复方案**: 添加线程锁保护全局配置修改
- **修复代码**:
```python
# 添加全局锁
_dashscope_lock = threading.Lock()

# 使用锁保护
with _dashscope_lock:
    if not hasattr(self, '_dashscope_api_key'):
        dashscope.api_key = self.config["dashscope_api_key"]
        self._dashscope_api_key = self.config["dashscope_api_key"]
```

#### 3.1.2 线程安全修复

**问题 3: ConfigManager 单例无锁保护**
- **文件**: `concurrent_monitor/core/config.py`
- **严重性**: 高危
- **描述**: 配置管理器单例初始化无线程安全保护
- **修复方案**: 使用双重检查锁定模式
- **修复代码**:
```python
class ConfigManager:
    _lock: threading.Lock = threading.Lock()
    
    @classmethod
    def initialize(cls, ...) -> Config:
        if cls._initialized:
            return cls._instance
        with cls._lock:  # 加锁保护
            if cls._initialized:
                return cls._instance
            # ... 初始化逻辑
```

**问题 4: 速率限制存储无锁保护**
- **文件**: `llm_coding_assistant/api_server.py`
- **严重性**: 高危
- **描述**: 全局速率限制存储在多线程环境下访问不安全
- **修复方案**: 添加线程锁保护所有访问
- **修复代码**:
```python
_rate_limit_lock: threading.Lock = threading.Lock()

@app.middleware("http")
async def rate_limit_middleware(request: Request, call_next):
    with _rate_limit_lock:
        # 所有速率限制操作
```

#### 3.1.3 内存安全修复

**问题 5: proposition_destroy 内存泄漏**
- **文件**: `src/core/proof.c`
- **严重性**: 高危
- **描述**: 栈分配失败时直接返回，导致命题永远不会被释放
- **修复方案**: 添加降级处理，直接释放命题资源
- **修复代码**:
```c
Proposition **destroy_stack = lv00_malloc(...);
if (!destroy_stack) {
    /* 降级处理：直接释放命题资源 */
    lv00_free((void **)&prop->input_port_ids);
    // ... 释放其他资源
    lv00_free((void **)&prop);
    return;
}
```

**问题 6: detect_conflicts 类型错误**
- **文件**: `python/lv00/core.py`
- **严重性**: 高危
- **描述**: sizes_ptr 声明为 c_int 而非指针，与 C 函数签名不匹配
- **修复方案**: 正确声明为指针类型
- **修复代码**:
```python
# 修复前
sizes_ptr = ctypes.c_int()

# 修复后
sizes_ptr = ctypes.POINTER(ctypes.c_int)()
```
