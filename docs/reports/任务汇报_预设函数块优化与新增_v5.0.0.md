## 六、代码风格规范

所有新增和修改的代码均遵循以下规范：

1. **头文件守卫**: 统一使用 `LV00_PRESET_XXX_H` 格式
2. **注释语言**: 全部中文 Doxygen 风格注释（`@file`、`@brief`、`@details`、`@param`、`@return`）
3. **版本号**: 统一 `@version 5.0.0`
4. **注册模式**: 使用 `register_xxx_preset()` 静态辅助函数 + `preset_blocks_register_simple()` 统一注册
5. **数学定义**: 每个预设包含 LaTeX 格式的数学定义
6. **复杂度标注**: 每个预设标注时间复杂度等级
7. **构造性/可逆性**: 每个预设标注构造性和可逆性标志
8. **日志输出**: 注册完成时使用 `PRESET_INFO_LOG` 输出日志
9. **公共接口**: 所有模块实现 `register()`、`count()`、`get_names()`、`category()` 四个接口
