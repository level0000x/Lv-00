## 三、第4轮新增项目的六条设计线索

| 线索 | 代表项目 | 核心启示 |
|:---|:---|:---|
| **元编程即DSL** | Lean 4、Coq/Ltac | 通过宿主语言宏系统和策略元编程，几何用户可以用 C API 组合自定义证明策略 |
| **内嵌优于外挂** | GiNaC、Lean 4 | 符号计算作为 C/C++ 语言的类型扩展，而非定义新的脚本语言 |
| **分层即弹性** | Why3、Dafny | 几何DSL → GVIL → 多后端 的三/四层翻译链，每层可独立演化 |
| **解释即学习** | Chuffed、Yices 2 | 每个约束传播步骤记录原因，冲突时生成 nogood 避免重复失败路径 |
| **模型即桥梁** | Yices 2 (MCSAT) | 在 SAT 搜索中直接构造理论模型，融合布尔推理与几何推理 |
| **声明即渲染** | JSXGraph | 声明式几何构造 API 直接驱动可视化，用户不需要手动管理渲染状态 |
